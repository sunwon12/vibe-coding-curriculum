# 스텝04 — 화면을 한 장으로 (원샷)

## 🎯 이 스텝에서 하는 일
내 앱에서 **가장 중요한 화면 1개**를, 들어갈 요소와 눌렀을 때의 동작까지 **글로** 정리합니다.

`⭐⭐ 보통 · 🕐 약 25분`

## 왜 이렇게 하나

"원샷 프레젠테이션"이라는 말이 있어요 — **아이디어를 화면 한 장으로 보여주면 말로 열 마디 하는 것보다 빠르게 전달**된다는 뜻이에요. 사람한테도 그렇고, AI한테는 특히 그래요.

그런데 예전엔 이 화면을 그리려고 **피그마(figma, 화면 디자인 프로그램)** 같은 걸 오래 붙들었어요. **바이브 코딩 시대엔 그럴 필요가 없어요.** 화면을 "글로" 또렷하게 설명하면, 다음 스텝(스텝05)에서 AI가 그걸 **바로 진짜 화면(코드)으로** 뽑아 줍니다. 피그마를 건너뛰는 거예요.

여기서도 원칙은 **바텀업**이에요. 유명한 앱 화면을 베끼지 말고, 스텝03에서 정한 **핵심 기능과 내 불편(Pain)/설렘(Wow)에서 화면을 도출**합니다. 레퍼런스(다른 앱)는 "저 버튼 위치 괜찮네" 정도로 **표현만 참고**하고, 무엇을 넣을지는 내 기능에서 나와야 해요.

## 이렇게 하세요

1. **`02_템플릿/화면정의.md` 파일을 엽니다.**

2. **가장 중요한 화면 1개만 고릅니다.**
   - 여러 화면이 떠올라도 지금은 **딱 하나** — 이 앱을 열면 제일 먼저·제일 자주 보는 화면이요. (보통 "입력 + 목록"이 같이 있는 메인 화면)

3. **그 화면에 들어갈 요소를 글로 적습니다.** 아래 4가지만 있으면 충분해요:
   | 무엇을 적나 | 예시 (가계부) |
   |---|---|
   | **제목** | "이번 달 지출" |
   | **입력(폼)** | 금액 칸, 메모 칸, "저장" 버튼 |
   | **목록** | 오늘 쓴 내역이 최신순으로 쭉 |
   | **버튼을 눌렀을 때 동작** | "저장"을 누르면 → 입력한 내역이 목록 맨 위에 뜬다 |

4. **분위기(느낌)를 한 마디로 적습니다.**
   - 디자인은 **근거 있는 단순한 한 마디**가 잘 먹혀요. 예: "노션처럼 차분하게", "블랙 & 화이트로 깔끔하게", "가계부니까 숫자가 잘 보이게".

5. **글이 어려우면 손그림도 좋아요.** 종이에 대충 그려 사진을 찍어 넣거나, 코치에게 "말로 설명할 테니 네가 요소로 정리해줘"라고 해도 됩니다.

6. **코치가 되물어 구체화해 줍니다.** 예: "저장하면 목록에 바로 뜨나요, 새로고침해야 뜨나요?", "빈칸으로 저장하면 어떻게 하죠?"

## 🤖 AI(코치)에게 줄 프롬프트

```
내 앱은 이거야: [빈칸 - 스텝02 한 문장 정의]
필수 기능 3개는: [빈칸 - PRD의 기능 3개]

이 앱에서 "가장 중요한 화면 1개"를 같이 정하고, 화면정의.md에 정리하고 싶어.
- 그 화면에 들어갈 요소(제목 / 입력 폼 / 목록 / 버튼)를 하나씩 되물어서 채워줘.
- 각 버튼을 눌렀을 때 무슨 일이 일어나는지(동작)도 정리해줘.
- 분위기는 한 마디로 정하자. 예: "노션처럼 차분하게".
- 다른 앱은 표현만 참고하고, 무엇을 넣을지는 내 기능에서 뽑아줘.
아직 코드는 짜지 마. 화면 한 장을 글로 또렷하게 만드는 게 목표야.
```

## ✅ 여기까지 하면 이렇게 보여요

- `화면정의.md`에 **메인 화면 1개**가 **요소(제목·입력·목록·버튼) + 동작 + 분위기**까지 적혀 있으면 성공이에요.
- 이 한 장이면 다음 스텝에서 AI가 바로 화면을 뽑을 수 있어요.
- **뭘 적을지 막막하면:** 코치에게 "이 앱을 열었을 때 내가 제일 먼저 뭘 보고 싶은지부터 되물어줘"라고 하세요.

> 이제 스텝05에서 이 화면정의를 그대로 넘겨서 **진짜로 첫 화면을 뽑습니다.** 드디어 눈에 보이는 결과가 나오는 첫 승리예요. 코치가 이 스텝을 확인하면 `진행상태.md`를 `- [x]`로, `상태.json`을 갱신해 줍니다.

## ⚠️ 자주 하는 실수

- **화면을 여러 개 한꺼번에 정의하려는 것.** 지금은 **가장 중요한 1개**만. 나머지는 나중에.
- **다른 앱을 그대로 베끼는 것.** 표현(색·배치)만 참고하고, 넣을 내용은 내 기능에서 뽑으세요.
- **동작을 안 적는 것.** "버튼을 누르면 뭐가 되는지"를 빼먹으면 AI가 헷갈려요. 꼭 적으세요.
- **분위기를 길게 설명하는 것.** "차분하고 세련되면서도 활기차고…" 말고 한 마디로. 짧을수록 잘 먹혀요.
