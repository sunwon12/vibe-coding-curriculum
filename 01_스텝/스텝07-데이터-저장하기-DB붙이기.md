# 스텝07 — 데이터 저장하기 (DB 붙이기)

## 🎯 이 스텝에서 하는 일
**새로고침해도 내 데이터가 사라지지 않도록**, 앱에 데이터 창고(DB)를 붙입니다.

`⭐⭐ 보통 · 🕐 약 40분`

## 왜 이렇게 하나

지금까지 만든 앱은 새로고침(F5)하면 입력한 게 **다 날아가요.** 왜냐면 데이터가 "화면에 잠깐 떠 있을 뿐" 어디에도 저장되지 않았거든요. 마치 화이트보드에 적은 글씨 같아요 — 지우면 끝.

데이터가 **남으려면** 어딘가에 적어둬야 해요. 그 "적어두는 창고"가 **DB(데이터베이스, 데이터를 저장해 두는 창고)**예요. 화이트보드 대신 **공책**에 옮겨 적는 거죠. 공책에 적으면 앱을 껐다 켜도, 새로고침해도 그대로 있어요.

우리는 **Supabase(수파베이스)**라는 서비스를 씁니다. 무료로 **DB와 로그인**을 주고, "설치하면 AI가 알아서 잘 쓰는" 조합이라 초보에게 잘 맞아요. (로그인 기능은 지금은 **선택**이에요. 이번 스텝에선 저장부터 확실히 하고, 로그인은 나중에 원하면 붙여요.)

한 가지 중요한 안전 규칙이 있어요. Supabase에 연결하려면 **비밀 키**(창고 열쇠 같은 것)가 필요한데, 이걸 **코드에 직접 쓰면 안 돼요.** 코드는 나중에 깃(코드 저장소)에 올라가는데, 열쇠까지 같이 올라가면 남이 내 창고를 열 수 있어요. 그래서 열쇠는 **환경변수(.env)**라는 별도 파일에 따로 보관하고, 그 파일은 **.gitignore(깃에 올리지 않을 목록)**에 넣어서 절대 밖으로 안 나가게 합니다. **이 처리는 전부 코치가 대신** 해줘요.

## 이렇게 하세요

1. **코치에게 Supabase 계정·프로젝트 만들기를 안내받으세요.** (아래 프롬프트 복붙)
   - 코치가 **손잡고** 알려줍니다: supabase.com에서 무료 회원가입 → 새 프로젝트 만들기 → 필요한 값 복사하기.
   - 회원가입·프로젝트 생성처럼 **웹사이트에서 버튼 누르는 부분**은 당신이 하고, 코치가 한 단계씩 짚어줘요.

2. **코치가 그 값(비밀 키)을 앱에 연결합니다.**
   - 코치가 비밀 키를 **환경변수(.env) 파일**에 넣고, `.env`를 **.gitignore**에 등록해요. 이건 코치가 알아서 처리합니다.
   - 당신이 할 일은 Supabase 화면에서 코치가 알려주는 값을 복사해 채팅에 붙여주는 정도예요.

3. **첫 데이터 한 건을 실제로 저장하고, 새로고침해서 확인하세요.**
   - 예: 할 일 하나("우유 사기")를 입력·추가한 뒤, 브라우저를 **새로고침**.
   - 새로고침해도 "우유 사기"가 그대로 있으면 **성공**이에요. 화이트보드가 공책이 된 순간이에요.

4. **잘 되면 코치가 저장점을 찍어줍니다.**

## 🤖 AI(코치)에게 줄 프롬프트

```
계획 먼저 말해줘. 어떻게 붙일 건지부터 설명하고, 그다음에 하자.

내 앱에 Supabase로 데이터 저장 기능을 붙여줘.
- Supabase 무료 계정이랑 프로젝트 만드는 걸 한 단계씩 손잡고 안내해줘. 나는 완전 초보야.
- 비밀 키는 코드에 직접 넣지 말고 환경변수(.env)로 빼고, .env는 .gitignore에 꼭 넣어줘.
- [예: 할 일 하나 "우유 사기"]를 저장해보고, 새로고침해도 남아 있는지 같이 확인하자.
- 로그인 기능은 지금은 붙이지 마. 저장부터 확실히 하고 싶어.
- 다 되고 확인되면 저장점(커밋) 찍어줘.
```

## ✅ 여기까지 하면 이렇게 보여요

- 데이터를 하나 넣고 **새로고침해도 그대로 남아** 있어요.
- 코치가 `.env`(비밀 키)가 **깃에 안 올라가게** 처리했다고 확인해 줬어요.
- **안 되면:** 저장이 안 되거나 빨간 글씨(에러)가 뜨면, 전문을 그대로 코치에게 붙이세요. DB 연결 에러는 아주 흔해요. → [[스텝08-막혔을때-에러-읽고-디버깅]]

> 코치는 저장→새로고침 확인이 되면 `진행상태.md`의 이 줄을 `- [x]`로 바꾸고 `상태.json`을 갱신합니다.

## ⚠️ 자주 하는 실수

- **비밀 키를 코드나 깃에 그대로 노출.** 절대 금지예요. 코드에 붙여넣지 말고 **환경변수(.env)**로. (코치가 챙기지만, 당신도 알고 있어야 해요.)
- **실제 사람의 개인정보를 입력.** 연습이니까 진짜 이름·전화번호·주소는 넣지 마세요. 가짜 예시로.
- **한 번에 로그인 + DB + 권한을 다 붙이려는 것.** 이번엔 **저장 하나**만. 로그인은 나중에 원하면.
- **새로고침 확인을 건너뛰기.** "저장된 것 같아요"가 아니라, **새로고침해서 남는 걸 눈으로** 봐야 진짜예요.
