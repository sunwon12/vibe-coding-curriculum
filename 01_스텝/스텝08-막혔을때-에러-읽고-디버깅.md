# 스텝08 — 막혔을 때: 에러 읽고 디버깅

## 🎯 이 스텝에서 하는 일
빨간 글씨(에러)가 떴을 때 겁먹지 않고, **차근차근 원인을 찾아 고치는 방법**을 익힙니다.

`⭐⭐ 보통 · 🕐 필요할 때마다 (막힐 때 언제든)`

> 📌 이건 순서상 8번이지만, **"막히면 언제든 돌아오는 처방전"**이에요. 스텝05든 07이든, 어디서 빨간 글씨가 떠도 이 문서로 돌아오세요. 순서대로 안 읽어도 됩니다.

## 왜 이렇게 하나

먼저 마음부터 풀고 갈게요. **에러(빨간 글씨)는 실패가 아니라 단서예요.** 개발자도 **하루 종일** 에러를 봐요. 에러가 뜬다는 건 컴퓨터가 "여기가 이상해요"라고 **위치를 알려주는 쪽지**를 준 거예요. 아무 말 없이 조용히 안 되는 것보다 훨씬 나아요.

초보가 실수하는 건 에러 자체가 아니라 **에러를 대하는 방식**이에요. 겁나서 창을 닫거나, 같은 걸 무한 반복하거나, 여러 개를 동시에 고치려다 더 꼬여요. 대신 아래 순서를 지키면 대부분 풀려요:

1. **전문을 그대로 붙인다.** 에러 글씨를 **일부만** 말고 **처음부터 끝까지** 복사해 코치에게. (핵심 단서가 아래쪽에 있을 때가 많아요.)
2. **"원인부터 설명해줘, 아직 코드는 고치지 마"** 라고 한다. 곧장 고치게 두면 뭘 왜 바꿨는지 모른 채 넘어가요.
3. **가능한 원인 3~4개를 받고, 하나씩** 시도한다. 한꺼번에 여러 개 X.
4. **그래도 안 보이면 로그를 추가**한다. 로그(코드가 지금 무슨 일을 하는지 찍어주는 메모)를 넣고 다시 돌려보면, 어디까지 잘 가다 막히는지 보여요.
5. **그래도 안 되면, 더 패치하지 말고 저장점으로 되돌린다.** 고치려다 더 망가지면, 마지막 저장점(스텝06에서 찍은 세이브 지점)으로 돌아가 다시 시도하는 게 훨씬 빨라요.

핵심 원칙: **패치보다 되돌리기.** 계속 덧대는 것보다, 안전한 지점으로 돌아가 다시 가는 게 초보에겐 최선일 때가 많아요.

## 이렇게 하세요

1. **에러 글씨를 전문 그대로 복사하세요.** (브라우저 화면의 빨간 글씨, 또는 Cursor 아래쪽 터미널의 빨간 줄 전부)
2. **코치에게 붙이면서 "원인부터 설명해줘, 아직 고치지 마"라고 하세요.** (아래 프롬프트 세트 1번)
3. **코치가 준 원인 후보를 하나씩** 시도합니다. 한 번에 하나만.
4. **안 풀리면** "지금까지 뭘 시도했지?"로 정리하거나(2번), 로그를 넣어 다시 보거나, 아예 다른 방법을 요청하세요(3번).
5. **더 망가졌으면** 저장점으로 되돌립니다(4번). 코치가 마지막 저장점으로 복원해 줘요.

## 🤖 AI(코치)에게 줄 프롬프트

막힐 때 상황별로 골라 쓰는 **프롬프트 세트**예요. 그대로 복붙하세요.

**① 에러가 떴을 때 (제일 먼저 이걸로):**
```
이 에러가 왜 나는지 쉬운 말로 원인부터 설명해줘. 아직 코드는 고치지 마.
가능한 원인을 3~4개로 정리해주고, 뭐부터 확인하면 좋을지 알려줘:

[여기에 에러 전문을 처음부터 끝까지 붙여넣기]
```

**② 여러 번 시도했는데 헷갈릴 때:**
```
우리가 지금까지 이 문제로 뭘 시도했는지 짧게 정리해줘.
그중에 아직 안 해본 방법이 있으면 알려줘.
```

**③ 같은 데서 계속 막힐 때:**
```
계속 같은 데서 막혀. 지금 방법은 접고, 아예 다른 방법을 제안해줘.
왜 그 방법이 나은지 한 줄로 설명도 해줘.
```

**④ 고치려다 더 망가졌을 때 (되돌리기):**
```
방금 바꾼 걸로 오히려 더 망가졌어. 더 고치지 말고,
마지막 저장점(커밋)으로 되돌려줘. 되돌리면 뭐가 사라지는지 먼저 알려주고 해줘.
```

## ✅ 여기까지 하면 이렇게 보여요

- 에러가 사라지고, 화면·기능이 **정상 동작**해요.
- 또는, 못 고쳤더라도 **저장점으로 되돌려 안전한 지점**으로 돌아왔어요 (망가진 채로 방치하지 않음).
- 어느 쪽이든 좋아요. **"고쳤다" 또는 "안전하게 되돌렸다"** 둘 중 하나면 이 처방전은 성공이에요.

> 참고: 자주 나오는 에러와 대처는 [[자주-막히는것-FAQ]]에 모아뒀어요. 프롬프트 원문은 [[프롬프트-치트시트]]에서 언제든 복사할 수 있어요.

## ⚠️ 자주 하는 실수

- **겁먹고 창을 닫아버리기.** 에러는 단서예요. 닫지 말고 전문을 붙이세요.
- **같은 프롬프트로 무한 재시도.** 두세 번 안 되면 접근을 바꾸거나(③) 되돌리세요(④). 같은 걸 반복하면 같은 결과예요.
- **에러를 일부만 붙이기.** 핵심 단서가 잘려나가요. **전문 전체**를 붙이세요.
- **여러 개를 동시에 고치기.** 뭐가 문제를 풀었는지 알 수 없게 돼요. **한 번에 하나씩.**
