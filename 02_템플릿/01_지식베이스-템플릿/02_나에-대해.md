# 나에 대해 (AI가 매번 읽는 내 컨텍스트)

> 길게 쓰지 마세요. **얇고 진짜인 게 길고 자동생성된 것보다 이겨요.** 핵심만.

## 나는

- (직업·상황: 예: 디자인 전공, 코딩은 처음)
- 지금 만드는 것: (예: 동네 책모임용 방명록 웹앱)
- 왜: (예: 매번 카톡으로 후기 받는 게 흩어져서)

## 원하는 톤 / 취향

- (예: 군더더기 없는 걸 좋아함 · 존댓말 · 이모지는 아주 조금)

## 하지 말 것 (AI가 자주 어기는 것)

- 어려운 용어를 설명 없이 쓰지 말 것
- 내 허락 없이 파일을 지우거나 크게 갈아엎지 말 것
- 한 번에 여러 개 고치지 말 것 (하나씩)

## 알아두면 좋은 배경

- (예: 맥북 씀 · 예산 0원, 무료 티어로만 · 아직 도메인 없음)
