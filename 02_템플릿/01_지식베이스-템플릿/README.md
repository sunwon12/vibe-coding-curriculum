# 내 지식베이스 (복사해서 바로 쓰는 템플릿)

이건 **AI에게 줄 나만의 지식베이스**예요. 내 배경·결정·취향·삽질을 여기에 쌓아두면,
Codex CLI·Claude Code 같은 AI가 이 폴더를 읽고 **"세상의 평균"이 아니라 "내 것"**을 내놓기 시작해요.

> 왜 이렇게 하는지 전체 그림은 커리큘럼의 **[[02_AI01-지식베이스-깔고-AI와-연결하기]]**를 보세요.

## 3분 시작 (코치에게 시키세요)

커리큘럼 안의 템플릿을 보고 있다면, 먼저 코치에게 **이 폴더 전체를 내 지식베이스 자리로 복사**해 달라고 하세요.
그 **복사본**을 비공개 GitHub 저장소로 만들고 Orca의 **Add Repo**에서 선택합니다. 이미 복사했다면 그 폴더를 쓰면 됩니다.
파일 목록에서 `index.md`를 열고 저장소 옆 `+`를 눌러 Codex나 Claude Code를 시작합니다. 내 답을 적거나 새 대화를 열 때도 이 복사본에서 합니다.
경로를 직접 확인해야 할 때만 Orca 터미널에서 아래 명령을 씁니다. 예시를 그대로 붙이지 말고 내
지식베이스 폴더의 실제 경로로 바꿉니다.

맥북 터미널:

```bash
cd "/내-지식베이스의-절대경로"
pwd
ls index.md AGENTS.md
codex
```

윈도우 PowerShell:

```powershell
Set-Location "C:\내-지식베이스의-절대경로"
Get-Location
Get-Item .\index.md, .\AGENTS.md
codex
```

Claude Code를 골랐다면 마지막 줄의 `codex`만 `claude`로 바꿉니다. 도구가 열리면 코치에게 이렇게
말하세요:

```
이 지식베이스 템플릿으로 내 걸 시작할래.
1) index.md를 보고 오늘 쓸 파일 하나를 고르게 해줘. 생활백서나 돈부터 시작해도 좋아.
2) 고른 파일의 질문을 하나씩 물어보고 내 답만 기록해줘.
   분야 일을 고르면 CLAUDE.md의 첫 인터뷰로 내 분야 폴더와 규칙부터 맞춰줘.
3) 새 대화에서 이 기록을 읽어 답하고, 반영한 조건과 사용한 파일을 알려줘.
4) 이 폴더를 비공개(private) 깃허브 저장소로 백업해줘.
```

끝이에요. 나머지(노트 추가·검색·지도 갱신)는 대화하다가 `/knowledge-base` 스킬이나 그냥 말로 시키면 돼요.

## 안에 뭐가 들었나

| 파일/폴더 | 뭐 하는 것 |
|---|---|
| `AGENTS.md` | **Codex CLI가 자동으로 읽는 진입점.** 아래 정본 규칙으로 연결해요. |
| `CLAUDE.md` | **AI가 폴더를 열면 가장 먼저 읽는 규칙.** "노트를 어디에 어떻게 쌓고 고치는지"가 적혀 있어, AI가 알아서 규칙대로 노트를 쌓아요. 내 분야 일하는 법은 여기 없어요. |
| `index.md` | **0홉 지도.** AI가 방향 잡는 목차. 폴더·최근 노트 한 줄 목록. |
| `01_나에-대해.md` | **AI가 매번 읽는 내 컨텍스트 한 장.** 이게 결과를 "내 것"으로 바꾸는 핵심. |
| `01_나/` | 내 취향·문체 같은 "나" 관련 노트 |
| `02_내-분야/` | **내 분야 폴더.** 첫 인터뷰에서 `02_임상심리/`·`02_건축/`처럼 내 분야 이름으로 바뀌어요. 일하며 내린 결정·교훈·양식을 쌓아요. |
| `02_내-분야/CLAUDE.md`·`AGENTS.md` | **내 분야에서 일하는 규칙.** 자주 하는 일과 결과물, 판단 기준, 용어, 하지 말 것. 루트 규칙은 파일 관리, 이건 일하는 법이에요. |
| `03_생활백서/` | 물건 구매·주거 선택·건강 습관을 기록할 파일. 질문에 답하며 내 생활 기준을 모아요. |
| `04_돈/` | 자산 현황·월급 배분·고정지출을 기록할 파일. 내 돈을 어떻게 쓰는지 정리해요. |
| `.claude/skills/knowledge-base/` | **`/knowledge-base` 스킬.** "노트 추가·검색·지도 갱신·복습"을 명령 한 줄로. 다른 도구에서는 현재 Skill 형식에 맞춰 코치가 변환해요. |
| `00_개인지식베이스를-바라보는-슬랙봇-빌드키트.md` | **선택형 설치 설명서.** 모바일 클라우드 앱으로 부족하고, 휴대폰의 Slack에서 로컬 지식베이스와 대화·기록하고 싶을 때만 AI에게 읽혀요. |

## 규칙 딱 3개만 기억하면 돼요

1. **1노트 = 1개념, 파일명 = 제목.** `RLS로-데이터-격리하기.md`(○) / `메모2.md`(×)
2. **새로 알면 새 파일 말고 기존 노트를 고쳐요.** 노트는 늘 "지금까지의 결론".
3. **내 답은 복사한 비공개 지식베이스에 적어요.** 공개 템플릿에는 질문과 가상 예시만 남겨요. 비밀번호·인증키는 기록하지 않아요.

모든 파일을 채울 필요는 없어요. `미기록`은 아직 모르는 상태로 남겨도 돼요. 파일 안의 **대화로 채우기 → 다음에 꺼내 쓰기**를 한 번 해보세요. 나머지는 `CLAUDE.md`에 있고, `AGENTS.md`가 Codex를 그 규칙으로 연결해 줘요.
