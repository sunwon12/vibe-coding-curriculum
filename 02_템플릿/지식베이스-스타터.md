# 지식베이스 스타터 키트

> **[[AI01-지식자산화-AI에게-줄-지식베이스-만들기]]에서 쓰는 실습 템플릿**이에요.
> "처음부터 지식베이스를 짜라"고 하면 빈 폴더 앞에서 막혀요. 그래서 **이미 다 만들어진 레포를 통째로** 드려요.
> 규칙 파일(`CLAUDE.md`)·지도(`index.md`)·스킬까지 들어 있어서, 복사하고 이름만 채우면 AI가 알아서 규칙대로 굴려요.

## 📦 복사할 실물은 여기 있어요

**`02_템플릿/지식베이스-템플릿/` 폴더 전체**가 복사용 완성 템플릿이에요. 이 폴더를 통째로 복사해서 내 지식베이스로 쓰면 돼요.

```
지식베이스-템플릿/
├── README.md              ← 이게 뭔지 + 3분 시작
├── CLAUDE.md              ← ⭐ AI가 먼저 읽는 규칙 (위키 프로토콜·폴더 규칙·frontmatter·안전)
├── index.md               ← 0홉 지도 (AI 진입점 목차)
├── 나에-대해.md            ← AI가 매번 읽는 내 컨텍스트 한 장
├── .claude/skills/knowledge-base/SKILL.md   ← /knowledge-base 스킬 (추가·검색·지도갱신·복습)
├── 01_나/                 ← 취향·문체 (_index + 예시 노트)
├── 02_결정과-배움/         ← 결정·삽질 (_index + 예시 노트)
└── 03_아이디어/            ← 막 담는 곳 (_index)
```

> 이 세 파일이 핵심이에요 — **`CLAUDE.md`**(AI가 규칙대로 굴러가게), **`index.md`**(AI가 먼저 읽는 지도), **`나에-대해.md`**(결과를 "내 것"으로). 왜 이게 중요한지는 [[AI01-지식자산화-AI에게-줄-지식베이스-만들기]]에서 설명해요.

## 🚀 3분 시작 (코치에게 시키기)

AI 편집기(Cursor/Antigravity/Claude Code)에 이 템플릿 폴더를 열고, 코치에게 이렇게 말하세요:

```
이 지식베이스 템플릿(지식베이스-템플릿 폴더)으로 내 걸 시작할래.
1) 이 폴더를 내 지식베이스 자리로 복사해줘.
2) 나에-대해.md를 지금 나한테 한 질문씩 물어보면서 같이 채워줘.
3) 다 되면 이 폴더를 비공개(private) 깃허브 저장소로 백업까지 해줘.
```

끝이에요. 이후 노트 추가·검색·지도 갱신은 `/knowledge-base` 스킬이나 그냥 말로 시키면 돼요.
(Cursor/Antigravity는 스킬 대신 `CLAUDE.md`를 읽어 같은 일을 말로 해줘요.)

## 규칙은 딱 3개만 기억하면 돼요 (나머진 CLAUDE.md에)

1. **1노트 = 1개념, 파일명 = 제목.** `RLS로-데이터-격리하기.md`(○) / `메모2.md`(×)
2. **새로 알면 새 파일 말고 기존 노트를 고쳐요.** 노트는 늘 "지금까지의 결론".
3. **개인정보·비밀번호는 넣지 말고, 저장소는 비공개(private)로.**
