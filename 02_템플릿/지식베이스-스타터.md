# 지식베이스 스타터 키트

> **[[AI01-지식베이스-깔고-AI와-연결하기]]에서 쓰는 실습 템플릿**이에요.
> "처음부터 지식베이스를 짜라"고 하면 빈 폴더 앞에서 막혀요. 그래서 **이미 다 만들어진 레포를 통째로** 드려요.
> 규칙 진입점(`AGENTS.md`·`CLAUDE.md`)·지도(`index.md`)·스킬까지 들어 있어서, 복사하고 이름만 채우면 AI가 알아서 규칙대로 굴려요.

## 📦 복사할 실물은 여기 있어요

**`02_템플릿/01_지식베이스-템플릿/` 폴더 전체**가 복사용 완성 템플릿이에요. 이 폴더를 통째로 복사해서 내 지식베이스로 쓰면 돼요.

```
지식베이스-템플릿/
├── README.md              ← 이게 뭔지 + 3분 시작
├── AGENTS.md              ← Codex CLI가 자동으로 읽는 규칙 진입점
├── CLAUDE.md              ← ⭐ 지식베이스 정본 규칙 (위키 프로토콜·폴더 규칙·frontmatter·안전)
├── index.md               ← 0홉 지도 (AI 진입점 목차)
├── 나에-대해.md            ← AI가 매번 읽는 내 컨텍스트 한 장
├── 개인지식베이스를-바라보는-슬랙봇-빌드키트.md ← 선택형. 모바일 클라우드로 부족할 때만 읽기
├── .claude/skills/knowledge-base/SKILL.md   ← /knowledge-base 스킬 (추가·검색·지도갱신·복습)
├── 01_나/                 ← 취향·문체 (_index + 예시 노트)
├── 02_내-분야/             ← 분야 일을 시작할 때 내 분야 이름으로 바뀜 (예: 02_임상심리/)
│   ├── CLAUDE.md          ← 이 분야에서 일하는 규칙
│   ├── AGENTS.md          ← Codex용 진입점
│   └── _index.md
├── 03_생활백서/             ← 생활에서 겪은 일과 선택 기준
│   ├── _index.md
│   ├── 물건-구매기준.md
│   ├── 주거-선택기준.md
│   └── 건강-생활습관.md
└── 04_돈/                 ← 내 돈의 현황과 사용 계획
    ├── _index.md
    ├── 자산-현황.md
    ├── 월급-배분계획.md
    └── 고정지출.md
```

> 규칙 파일이 두 층이에요. **루트 `CLAUDE.md`는 노트를 쌓고 고치는 규칙**, **분야 폴더 `CLAUDE.md`는 그 분야
> 일을 하는 규칙**이에요. 개발자·임상심리사·건축학도의 지식베이스는 관리 규칙은 같고 일하는 규칙만 달라요.

> 이 파일들이 핵심이에요 — **`AGENTS.md`·`CLAUDE.md`**(도구에 맞춰 AI가 규칙대로 굴러가게), **`index.md`**(AI가 먼저 읽는 지도), **`나에-대해.md`**(결과를 "내 것"으로). 왜 이게 중요한지는 [[AI01-지식베이스-깔고-AI와-연결하기]]에서 설명해요.

## 🚀 3분 시작 (코치에게 시키기)

커리큘럼에서 실행한 코치에게 이렇게 말하세요. **내 답을 쓰기 전에 Orca의 Add Repo에서 복사본을 선택하고, 그 복사본에서 새 대화를 시작합니다.**

```
이 지식베이스 템플릿(지식베이스-템플릿 폴더)으로 내 걸 시작할래.
1) 이 템플릿을 내 지식베이스 자리로 복사하고 원본·복사본 경로를 알려줘.
2) 복사본을 Orca에서 열어 새 대화를 시작하도록 안내해줘. 이후 기록과 백업은 복사본에서 해줘.
3) 기본 폴더에서 오늘 쓸 파일 하나를 고르게 하고, 질문을 하나씩 물어 내 답만 기록해줘.
   분야 일을 고르면 CLAUDE.md의 첫 인터뷰로 내 분야 폴더와 규칙부터 맞춰줘.
4) 복사본에서 다시 새 대화를 열어 이 기록을 읽고, 어떤 조건을 반영했는지 확인하게 해줘.
5) 복사본을 비공개(private) 깃허브 저장소로 백업해줘.
```

끝이에요. 이후 노트 추가·검색·지도 갱신은 `/knowledge-base` 스킬이나 그냥 말로 시키면 돼요.
(도구마다 Skill 형식이 다르면 코치가 현재 공식 형식을 확인해 맞춰 줍니다.)

> **파일을 열면 답할 질문과 다음에 써먹을 질문이 있어요.** 생활백서·돈의 파일 중 지금 필요한 하나만 채워 보세요. `미기록`은 모르는 상태로 남겨도 되고, 가상 예시는 내 정보로 쓰지 않아요.
> 기본 폴더 아래는 기록이 쌓여 찾기 어려울 때 나눠요 → [[지식베이스-폴더분류-어떻게-나눌까]]

## 규칙은 딱 3개만 기억하면 돼요 (나머진 CLAUDE.md에)

1. **1노트 = 1개념, 파일명 = 제목.** `RLS로-데이터-격리하기.md`(○) / `메모2.md`(×)
2. **새로 알면 새 파일 말고 기존 노트를 고쳐요.** 노트는 늘 "지금까지의 결론".
3. **내 답은 복사한 비공개 지식베이스에 적어요.** 공개 템플릿에는 질문과 가상 예시만 남겨요. 비밀번호·인증키는 기록하지 않아요.
