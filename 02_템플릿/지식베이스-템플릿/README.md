# 내 지식베이스 (복사해서 바로 쓰는 템플릿)

이건 **AI에게 줄 나만의 지식베이스**예요. 내 배경·결정·취향·삽질을 여기에 쌓아두면,
Codex CLI·Claude Code 같은 AI가 이 폴더를 읽고 **"세상의 평균"이 아니라 "내 것"**을 내놓기 시작해요.

> 왜 이렇게 하는지 전체 그림은 커리큘럼의 **[[AI01-지식베이스-깔고-AI와-연결하기]]**를 보세요.

## 3분 시작 (코치에게 시키세요)

먼저 이 폴더를 비공개 GitHub 저장소로 만든 뒤, Orca의 **Add Repo**에서 선택합니다. 파일 목록에서
`index.md`를 열고 저장소 옆 `+`를 눌러 Codex나 Claude Code를 시작하면 AI도 같은 폴더를 봅니다.
경로를 직접 확인해야 할 때만 Orca 터미널에서 아래 명령을 씁니다. 예시를 그대로 붙이지 말고 내
지식베이스 폴더의 실제 경로로 바꿉니다.

맥북 터미널:

```bash
cd "/내-지식베이스의-절대경로"
pwd
ls index.md AGENTS.md
codex
```

윈도우 PowerShell:

```powershell
Set-Location "C:\내-지식베이스의-절대경로"
Get-Location
Get-Item .\index.md, .\AGENTS.md
codex
```

Claude Code를 골랐다면 마지막 줄의 `codex`만 `claude`로 바꿉니다. 도구가 열리면 코치에게 이렇게
말하세요:

```
이 지식베이스 템플릿으로 내 걸 시작할래.
1) 나에-대해.md를 한 질문씩 물어보면서 같이 채워줘.
2) 다 되면 이 폴더를 비공개(private) 깃허브 저장소로 백업해줘.
```

끝이에요. 나머지(노트 추가·검색·지도 갱신)는 대화하다가 `/knowledge-base` 스킬이나 그냥 말로 시키면 돼요.

## 안에 뭐가 들었나

| 파일/폴더 | 뭐 하는 것 |
|---|---|
| `AGENTS.md` | **Codex CLI가 자동으로 읽는 진입점.** 아래 정본 규칙으로 연결해요. |
| `CLAUDE.md` | **AI가 폴더를 열면 가장 먼저 읽는 규칙.** "이 지식베이스를 어떻게 쓰고 관리하는지"가 적혀 있어, AI가 알아서 규칙대로 노트를 쌓아요. |
| `index.md` | **0홉 지도.** AI가 방향 잡는 목차. 폴더·최근 노트 한 줄 목록. |
| `나에-대해.md` | **AI가 매번 읽는 내 컨텍스트 한 장.** 이게 결과를 "내 것"으로 바꾸는 핵심. |
| `01_나/` | 내 취향·문체 같은 "나" 관련 노트 |
| `02_결정과-배움/` | 내가 내린 결정과 이유, 삽질·교훈 (예시 노트 1개 들어있음) |
| `03_아이디어/` | 떠오른 걸 막 담는 곳 |
| `.claude/skills/knowledge-base/` | **`/knowledge-base` 스킬.** "노트 추가·검색·지도 갱신·복습"을 명령 한 줄로. 다른 도구에서는 현재 Skill 형식에 맞춰 코치가 변환해요. |
| `개인지식베이스를-바라보는-슬랙봇-빌드키트.md` | **선택형 설치 설명서.** 모바일 클라우드 앱으로 부족하고, 휴대폰의 Slack에서 로컬 지식베이스와 대화·기록하고 싶을 때만 AI에게 읽혀요. |

## 규칙 딱 3개만 기억하면 돼요

1. **1노트 = 1개념, 파일명 = 제목.** `RLS로-데이터-격리하기.md`(○) / `메모2.md`(×)
2. **새로 알면 새 파일 말고 기존 노트를 고쳐요.** 노트는 늘 "지금까지의 결론".
3. **개인정보·비밀번호는 넣지 말고, 저장소는 비공개(private)로.**

나머지는 `CLAUDE.md`에 다 적혀 있고, `AGENTS.md`가 Orca에서 실행한 Codex를 그 규칙으로 연결해 줘요.
