# 화면 정의

> [[스텝04-화면을-한장으로-원샷]]에서 씁니다. [[PRD]]의 "화면 목록"에 적은 화면을 **하나씩** 여기서 자세히 그려요.
> 이 표를 잘 채워두면, 다음 스텝([[스텝05-첫-화면-바로-뽑기]])에서 AI에게 이 내용을 그대로 주고 화면을 뽑을 수 있어요.
> **처음엔 메인 화면 딱 하나만** 정의해도 충분해요. 욕심내지 마세요.

**채우는 법:** 아래 표의 오른쪽 칸(빈칸)을 채우세요. 그림 실력 필요 없어요. 말로 적으면 돼요.

---

## 메인 화면 (빈칸 — 채우세요)

| 항목 | 내용 |
|---|---|
| **화면 이름** | (예: 메인 화면) |
| **목적** | (이 화면에서 사용자가 뭘 하나? 한 줄로) |
| **들어갈 요소** | (제목 / 입력칸 / 버튼 / 목록 등 — 화면에 보이는 것들을 나열) |
| **눌렀을 때 동작** | (버튼을 누르면·입력하면 무슨 일이 일어나나?) |
| **분위기** | (예: 노션처럼 차분하게 / 블랙&화이트 / 파스텔톤 밝게) |

> 화면이 여러 개면, 위 표를 복사해서 아래에 하나 더 만들면 돼요.

## ✍️ 이미 채운 예시 — "혼자 쓰는 30초 가계부" 메인 화면

| 항목 | 내용 |
|---|---|
| **화면 이름** | 메인 화면 (입력 + 내역) |
| **목적** | 지출을 30초 안에 한 줄로 적고, 지금까지 적은 내역과 이번 달 합계를 본다 |
| **들어갈 요소** | 맨 위에 "이번 달 합계" 큰 숫자 / 그 아래 항목 입력칸(예: 커피) + 금액 입력칸(예: 4500) + `추가` 버튼 / 그 아래 내역 목록(최신 게 위로, 각 줄에 항목·금액·삭제 버튼) |
| **눌렀을 때 동작** | `추가` 버튼을 누르면 입력한 내역이 목록 맨 위에 생기고, 이번 달 합계 숫자가 그만큼 올라감 / 각 내역의 삭제 버튼을 누르면 그 줄이 사라지고 합계도 줄어듦 |
| **분위기** | 노션처럼 차분하고 심플하게, 흰 배경에 검정 글씨, 숫자만 살짝 강조 |
