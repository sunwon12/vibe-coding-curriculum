# 용어집 (비개발자용)

> 만들다 보면 낯선 단어가 나와요. 겁먹지 마세요. 아래 표에서 찾으면 **한 줄 비유**로 감이 와요.
> 코치는 어려운 말을 즉시 풀어주지만, 혼자 확인하고 싶을 때 이 표를 펴세요.

## AI 자체를 가리키는 말 (2축)

> AI를 쓸 때 **사람이 실제로 손대는 레버는 둘뿐**이에요 —
> **①주입**(무엇을 넣는가: AI는 내 사정을 모르니 꺼내서 읽혀야 함) **②컨텍스트 관리**(유한한 책상을 어떻게 쓰는가).
> 나머지 용어는 **못 바꾸는 전제**이거나, **두 축의 자동화 수단**이거나, **사람이 확인해야 할 안전선**이에요.
> 축째로 이해하고 싶으면 → [[AI00-AI를-다루는-2축-암묵지-주입과-컨텍스트-관리]]

| 용어 | 어디에 걸리나 | 쉬운 뜻 · 비유 |
|---|---|---|
| **컨텍스트** | **축2** | AI가 답할 때 보는 **책상 위 전부** — 지금까지의 대화 + 규칙 파일 + 붙인 자료 |
| **컨텍스트 윈도우** | **축2** | 그 책상 크기. 넘치면 오래된 게 밀려남 → **"아까 정한 걸 까먹는" 진짜 이유** |
| **토큰** | **축2** | 책상 위 분량을 재는 단위(글자 조각). 요금·속도도 여기에 비례 |
| **컴팩트(compact)** | **축2** | 길어진 대화를 요약해 눌러 담기. **손실 압축**이라 중요한 건 먼저 파일로 빼둘 것 |
| **지식베이스 / 규칙 파일** | **축1** | 내 암묵지·기준을 글로 꺼내 AI가 매번 읽게 만든 것 |
| **RAG** | **축1+2** | 재료를 쌓아 두고(1) 그중 **필요한 것만 골라 올려 주는**(2) 장치 |
| **파인튜닝** | **축1의 변종** | 얼어붙은 손잡이를 조금 다시 돌리는 비싼 작업. 초보 문제는 대개 축1·2로 해결됨 |
| **모델** | 전제 | AI 본체인 거대한 수식 덩어리. 학습이 끝난 순간 **얼어붙어서 대화로는 안 변함** |
| **파라미터** | 전제 | 그 수식에 달린 숫자 손잡이. "수천억 개"라는 게 이 개수 |
| **환각(할루시네이션)** | 전제 → 안전선 | 모르는 걸 **자신 있게 지어내는 것.** 없앨 순 없고 **줄이고 확인**하는 것 |
| **MCP** | 두 축의 자동화 | AI에게 도구(슬랙·노션·DB·파일)를 꽂아 주는 **표준 콘센트** |
| **에이전트** | 두 축의 자동화 | 그 손으로 **생각→실행→결과 확인을 스스로 반복**하는 AI. Cursor가 파일을 직접 고치는 게 이것 |

## 도구를 다루는 말

| 용어 | 쉬운 뜻 · 비유 |
|---|---|
| **터미널** | 컴퓨터에게 글자로 명령을 내리는 검은 창. 마우스 대신 타이핑으로 시키는 리모컨. (명령은 보통 코치가 대신 침) |
| **프롬프트** | AI에게 시키려고 쓰는 말·부탁. 요리사(AI)에게 건네는 주문서. 구체적일수록 원하는 게 나옴 |
| **로그** | 프로그램이 "지금 여기까지 왔어요", "이 값은 이거예요" 하고 남기는 중간 메모. 문제 찾을 때의 발자국 |
| **체크포인트 / 저장점** | 게임 세이브 포인트. 잘 되던 순간을 저장해두면 망가져도 그때로 되돌아갈 수 있음 |

## 코드가 올라가고 인터넷에 보이기까지

> 💡 이 묶음은 **"내 컴퓨터(로컬) ↔ 인터넷 창고(원격)"** 두 곳을 오가는 이야기예요.
> **git은 구글 문서처럼 자동 동기화가 아니라, 내가 올리고 내가 받아야** 합니다.
> 방향을 그림으로 잡고 싶으면 → [[04_원격과-로컬-깃허브와-내-컴퓨터-연결하기]]

| 용어 | 쉬운 뜻 · 비유 |
|---|---|
| **git (깃)** | 내 작업의 "타임머신+세이브 관리자". 언제 뭘 바꿨는지 기록하고 되돌릴 수 있게 해줌 |
| **레포 / 리포지토리** | 내 프로젝트 파일이 통째로 담긴 상자(폴더). "repository=저장소"의 줄임말 |
| **로컬 (local)** | **내 컴퓨터에 있는 사본.** 실제 작업은 전부 여기서 함 |
| **원격 (remote)** | **인터넷에 있는 원본 창고**(GitHub). 백업이자 공유 지점 |
| **origin (오리진)** | 내 폴더가 기억하고 있는 **"내 창고 주소"의 별명.** "네 창고는 저기야"를 등록해 둔 것 |
| **클론 (clone)** | 원격 → 로컬. **처음 한 번**, 창고에서 사본을 통째로 가져와 새 폴더로 만드는 것 |
| **풀 (pull)** | 원격 → 로컬. 이미 있는 사본에 **바뀐 것만** 받아오기. 작업 시작 전 습관 |
| **커밋 (commit)** | 지금까지 한 작업에 "여기 저장!" 도장 찍기. **⚠️ 아직 내 컴퓨터 안 — 인터넷엔 안 감** |
| **푸시 (push)** | 로컬 → 원격. 내 저장점을 인터넷 창고로 **올리기.** 커밋과 푸시는 다른 단계 |
| **충돌 (conflict)** | 같은 파일을 **양쪽에서 따로 고쳐** 부딪힌 상태. 겁낼 일 아니고 코치와 정리하면 됨 |
| **GitHub (깃허브)** | 내 코드를 올려두는 인터넷 창고. 배포·협업의 출발점이 되는 클라우드 서랍 |
| **배포 (deploy)** | 내 앱을 인터넷에 올려서 **남이 링크로 볼 수 있게** 하는 것. 가게 문 여는 것 |
| **서버** | 내 앱을 24시간 돌려서 사람들에게 보여주는 남의 컴퓨터. 항상 켜져 있는 가게 |
| **localhost (로컬호스트)** | "내 컴퓨터 안에서만" 도는 연습용 주소. 나만 볼 수 있는 미리보기. 남에겐 안 보임 |

## 앱이 어떻게 생겼나 (구조)

| 용어 | 쉬운 뜻 · 비유 |
|---|---|
| **프론트엔드** | 사용자 눈에 **보이는** 화면 부분. 식당의 홀·메뉴판·인테리어 |
| **백엔드** | 눈에 안 보이지만 뒤에서 **일하는** 부분(저장·계산·처리). 식당의 주방 |
| **데이터베이스 (DB)** | 데이터를 차곡차곡 저장하는 창고. 정리된 거대한 엑셀 표라고 보면 됨 |
| **API** | 프로그램끼리 대화하는 **창구·주문 카운터**. "이거 주세요" 하면 "여기요" 하고 돌려주는 규칙 |
| **API 키** | 그 창구를 쓸 수 있는 **내 전용 열쇠·비밀번호**. 남에게 보이면 안 됨 |
| **환경변수** | 비밀 값(열쇠·비밀번호)을 코드 밖에 따로 빼서 보관하는 칸. 코드에 직접 안 쓰기 위한 금고 |
| **.env** | 그 환경변수(비밀 값)를 적어두는 파일. 절대 인터넷에 올리면 안 되는 금고 파일 |
| **.gitignore** | "이 파일들은 인터넷에 올리지 마" 명단. `.env` 같은 비밀 파일을 여기 넣어 보호 |

## 만들 때 쓰는 재료들 (스택)

| 용어 | 쉬운 뜻 · 비유 |
|---|---|
| **프레임워크** | 앱을 빨리 만들게 뼈대·기본 부품을 미리 갖춘 세트. 밀키트(반조리 재료)처럼 |
| **Next.js (넥스트)** | 이 커리큘럼이 쓰는 웹앱 프레임워크. 화면·서버를 한 번에 만들게 해주는 밀키트 |
| **라이브러리** | 남이 미리 만들어둔 기능 묶음. 필요할 때 가져다 쓰는 부품 상자 |
| **컴포넌트** | 화면을 이루는 재사용 블록(버튼·입력칸·카드 등). 레고 조각 하나 |
| **Tailwind (테일윈드)** | 색·여백·크기를 짧은 단어로 빠르게 꾸미는 디자인 도구. 옷에 붙이는 스티커 세트 |
| **shadcn/ui** | 예쁘게 다듬어진 컴포넌트(버튼·입력칸 등) 모음. 바로 쓰는 완성형 부품 키트 |
| **Supabase (수파베이스)** | 데이터 저장·로그인을 무료로 붙여주는 서비스. 손쉬운 클라우드 창고+경비원 |
| **Vercel (버셀)** | 만든 앱을 클릭 몇 번으로 인터넷에 올려주는 무료 배포 서비스. 자동 오픈 도우미 |

## 상태를 가리키는 말

| 용어 | 쉬운 뜻 · 비유 |
|---|---|
| **에러 (error)** | 뭔가 막혀서 진행이 멈춘 상태 + 그 안내 메시지(빨간 글씨). "여기 좀 봐줘"라는 메모 |
| **버그 (bug)** | 안 멈추지만 **원하는 대로 안 도는** 문제. 계산이 틀리거나 버튼이 헛도는 것 |
| **반응형** | 휴대폰·태블릿·PC 등 **화면 크기에 맞춰** 안 깨지고 잘 보이게 만드는 것 |
| **MVP** | Minimum Viable Product. **일단 돌아가는 가장 작은 버전**. 핵심 기능 하나만 담은 첫 완성품 |
| **프로토타입** | 대충 만들어 확인하는 **시제품·초안**. 완벽함 대신 "되는지"를 먼저 보는 것 |
