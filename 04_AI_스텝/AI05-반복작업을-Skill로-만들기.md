# AI05 — 반복 작업을 Skill로 만들기

## 이 스텝에서 하는 일

한 번 성공해 프로세스가 정해진 자동화를 **다음에도 같은 방식으로 꺼내 쓰는 Skill(스킬)**로 만듭니다. Skill은 코드 묶음이 아니라, AI가 필요할 때 읽는 **반복 작업 매뉴얼**입니다. 매번 같은 긴 지시를 치기 귀찮아진 순간이 만들 때입니다.

`⭐⭐ 보통 · 약 30분 · 코드는 코치가 처리`

## 언제 Skill로 만드나요?

다음 셋이 모두 맞을 때 만듭니다.

- 같은 종류의 일을 **세 번 이상** 했다.
- 시작 조건과 원하는 결과를 말로 설명할 수 있다.
- 한 번 쓴 프롬프트가 아니라 **다음 사례에도 같은 절차**가 필요하다.

아직 한 번도 성공하지 않은 일을 먼저 Skill로 만들면 실패 절차만 자동화할 수 있습니다. 수동으로 한 번 성공한 뒤 고정하세요.

## Skill에는 여섯 가지만 담습니다

| 항목 | 묻는 말 |
| --- | --- |
| 호출 신호 | 사용자가 어떤 말을 하면 이 Skill을 쓰나요? |
| 입력 | 시작 전에 어떤 파일·정보가 필요한가요? |
| 절차 | 어떤 순서로 하나요? |
| 결과 | 무엇을 어디에 남기나요? |
| 검증 | 제대로 됐는지 무엇으로 확인하나요? |
| 중단선 | 어떤 경우에는 사람에게 물어야 하나요? |

일반 상식, 긴 배경 설명, 모든 예외를 한 파일에 넣지 않습니다. **이 Skill을 실행할 때 결과를 바꾸는 내용만** 남기고, 긴 참고 자료는 별도 문서에 둔 뒤 필요할 때만 읽게 연결합니다.

## 만드는 순서

1. 최근에 성공한 사례 하나를 코치에게 보여줍니다.
2. 코치가 위 여섯 항목을 질문으로 추출합니다.
3. 코치가 현재 AI 도구에 맞는 Skill 위치와 형식을 확인해 파일을 만듭니다.
4. **새 사례**로 다시 실행합니다. 방금 성공한 예를 그대로 재사용하면 검증이 아닙니다.
5. 빠진 단계만 고치고, 실제로 쓰이지 않은 설명은 지웁니다.

## 코치에게 줄 말

```text
내가 반복한 [업무]를 다음에도 재사용할 Skill로 만들어줘.
먼저 최근 성공 사례에서 호출 신호·입력·절차·결과·검증·중단선을 질문으로 뽑아줘.
내 도구가 쓰는 Skill 형식과 설치 위치는 네가 확인하고, 긴 배경은 본문에 넣지 말고 필요할 때만 읽는 참고 문서로 분리해줘.
완성 뒤에는 이전 사례 말고 새 사례로 실제 실행해 검증해줘.
```

## 완료 기준

- 평범한 말로 요청했을 때 Skill이 필요한 상황을 알아봅니다.
- 새 사례에서 같은 형태의 결과가 나옵니다.
- 틀렸을 때 멈추거나 사람이 확인하는 지점이 있습니다.
- Skill을 읽지 않는 작업에는 불필요한 내용이 컨텍스트로 들어오지 않습니다.
