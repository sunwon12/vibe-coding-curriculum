# AI 스텝 — AI에게 내 일을 맡기는 법

> **누구용:** 코딩을 배우려는 사람이 아니라도 됩니다. AI에게 내 자료와 기준을 알려 주고, 실제 도구를 붙여 반복 업무를 줄이고 싶은 사람을 위한 독립 과정입니다.
>
> **결과:** 코드 읽기가 아니라, **내 일 하나를 찾아 AI가 내 맥락으로 실제 수행하고 다음에도 반복하게 만드는 것**입니다.

> **시작 전:** AI 도구 설치와 GitHub 체크포인트는 이 트랙만의 내용이 아니라 커리큘럼 공통 기반입니다. 먼저 [[02_AI-도구-고르고-CLI-설치하기]]와 [[03_GitHub로-체크포인트와-동기화-만들기]], [[04_AI에게-일-맡기는-프롬프트-쓰는-법]]을 끝냅니다.

| AI가 내 사정과 기준을 모른다 | AI02 암묵지 |
| 무엇을 기록하고 언제 읽힐지 모르겠다 | AI03 주입·호출 설계 |
| 파일·화면·서비스를 직접 못 만진다 | AI04 손발 |
