# AI02 — AI가 안 헤매게: 규칙과 계획을 파일로 고정하기

## 🎯 이 스텝에서 하는 일
AI가 대화가 길어져도 **앞서 정한 규칙을 잊지 않게**, 프로젝트 규칙과 계획을 **말이 아니라 파일로** 고정합니다.

`⭐⭐ 보통 · 🕐 약 30분` · 💡 번호는 11이지만 **가장 먼저 들이면 좋은 기초 습관**이에요(제품01과 짝).

## 🔔 이 모듈이 필요한 신호

- 대화가 길어지면 AI가 **앞에서 정한 걸 잊고** 엉뚱한 데를 바꾼다.
- **같은 실수를 자꾸 반복**한다(비밀키를 코드에 박거나, 건드리지 말라던 화면을 또 건드림).
- 새 대화(세션)를 열 때마다 **처음부터 다시 설명**해야 한다.

## 왜 이렇게 하나

AI는 대화의 맥락(컨텍스트 — 지금까지 오간 이야기)을 **대화창을 새로 열면 다 잊어버려요.** 그래서 "매번 말로 설명"하면
말할 때마다 조금씩 달라지고, 길어지면 앞 내용을 놓칩니다. 이게 [[제품04-안-무너지게-테스트-모니터링-백업]]에서 말한
**"한 곳 고치면 엉뚱한 데가 깨진다(회귀)"의 근본 원인**이에요.

해법은 간단해요. **매번 말하지 말고, 규칙과 계획을 프로젝트 안에 파일로 적어두는 것.** 그러면 AI가 **매 세션 그 파일을
먼저 읽고** 일관되게 움직입니다. 요리로 치면, 매번 구두로 지시하는 대신 **주방 벽에 "우리 집 원칙"을 붙여두는** 거예요.

> 사실 **지금 당신이 쓰는 이 커리큘럼 레포가 바로 그렇게 만들어졌어요.** 루트의 `AGENTS.md`(코치 규칙)와 `상태.json`이
> 그 "벽에 붙인 원칙"이라, 코치가 매번 그걸 읽고 당신을 이끄는 거죠. **당신 앱에도 똑같이 만들면 됩니다.**
> (이건 Cursor의 Rules, Claude Code의 `CLAUDE.md`, 안티그래비티의 `.agents/rules/`, 그리고 계획 우선(Plan Mode) 습관 —
> 전 세계 심화 커리큘럼이 **가장 앞에** 두는 표준이에요.)

## 이렇게 하세요

1. **프로젝트 규칙 파일을 만든다.** (코치가 만들어줘요)
   - 도구에 맞게: **Cursor·안티그래비티 → `AGENTS.md`**, **Claude Code → `CLAUDE.md`**.
   - 담을 것: ① 이 앱이 뭔지 한두 줄 ② 스택(Next.js·Supabase 등) ③ **절대 하지 말 것**(비밀키를 코드에 박지 마 / 로그인 화면은 함부로 바꾸지 마 / 이 폴더는 건드리지 마) ④ 새 기능은 **계획부터** 보여주기.
   - **짧게.** 200줄 넘어가면 AI가 오히려 흘려요. 핵심만.
2. **기능 착수 전 "계획 먼저"를 습관으로.** 바로 코드 말고 "어떻게 할지 계획부터"를 요청하고, 그 계획을 짧은 파일(예: `docs/계획-이번기능.md`)에 남긴 뒤 그걸 보며 진행. (Cursor·안티그래비티엔 "Plan Mode(계획 모드)"가 있어요.)
3. **기능마다 새 대화 + 규칙 파일은 그대로.** 대화는 깨끗하게 새로 열되(맥락이 안 꼬이게), 규칙 파일은 항상 남아 있으니 AI는 매번 같은 원칙을 따릅니다.

## 🤖 AI(코치)에게 줄 프롬프트

```
이 프로젝트용 규칙 파일(Cursor면 AGENTS.md / Claude Code면 CLAUDE.md)을 만들어줘. 내용:
- 이 앱은 [무엇을 하는 앱].
- 스택: [예: Next.js + Supabase + Tailwind].
- 절대 하지 말 것: 비밀키를 코드에 직접 넣지 마(항상 환경변수), [이 화면/폴더]는 내 허락 없이 바꾸지 마.
- 새 기능은 코드 짜기 전에 계획부터 보여주고 내 승인을 받아.
앞으로 매 작업에서 이 규칙을 먼저 읽고 따라줘. 200줄 넘지 않게 핵심만.
```

```
이 기능 [무슨 기능]을 만들기 전에, 어떻게 할지 계획부터 세워서 docs/계획-[기능이름].md에 적어줘.
내가 그 계획을 읽고 "좋아"라고 하기 전엔 코드를 짜지 마.
```

## ✅ 여기까지 하면 이렇게 보여요

- 프로젝트 루트에 **규칙 파일(AGENTS.md 또는 CLAUDE.md)**이 생겼어요.
- **새 대화창을 열어도** AI가 그 규칙(하지 말 것 등)을 알아서 지킵니다 — "비밀키 코드에 넣지 마"를 다시 말 안 해도 됨.
- 기능 착수 때 AI가 **계획부터** 보여줘요.

> 코치는 규칙 파일이 생기고 새 세션에서도 규칙이 지켜지는 걸 확인하면 `진행상태.md`의 이 줄을 `- [x]`로, `상태.json`을 갱신해 줍니다.

## ⚠️ 자주 하는 실수

- **규칙을 파일로 안 하고 매번 말로 반복.** 그래서 매번 조금씩 달라지고 AI가 흘려요. 파일로 고정하세요.
- **규칙 파일이 너무 길다.** 200줄 넘으면 AI가 무시하기 시작해요. "하지 말 것" 중심으로 핵심만.
- **계획 없이 큰 기능을 한 방에.** 계획→승인→코드 순서를 지켜야 엉뚱한 결과를 안 만들어요.
- **규칙끼리 모순.** "A로 해" / "A 하지 마"가 섞이면 AI가 헷갈려요. 정리해서 하나로.
