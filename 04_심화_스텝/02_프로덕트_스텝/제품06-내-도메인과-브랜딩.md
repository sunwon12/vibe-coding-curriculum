# 제품06 — 내 도메인과 브랜딩

## 🎯 이 스텝에서 하는 일 (한 줄)
임시 주소(`xxx.vercel.app`) 대신 **내 도메인**을 붙이고, 카톡·SNS에 링크를 보냈을 때 **미리보기 카드가 예쁘게 뜨게** 만듭니다.

`⭐⭐ 보통 · 🕐 약 35분`

## 🔔 이 모듈이 필요한 신호
- 임시 주소(`내앱-어쩌고.vercel.app`)가 아니라 **내 이름의 주소**(`내앱.com`)를 갖고 싶다.
- 카톡·인스타·트위터에 링크를 보내면 **미리보기가 안 뜨거나** 엉뚱한 그림·글자가 뜬다.

## 왜 이렇게 하나

지금 당신 앱 주소는 `무슨무슨-app-1234.vercel.app`처럼 생겼을 거예요. 돌아가는 데는 문제없지만, 남에게 보여줄 때 **"진짜 서비스"로 안 보여요.** 사람들은 주소만 보고도 신뢰 여부를 반사적으로 판단하거든요. **내 도메인**(예: `myapp.com`)이 있으면 그 자체로 "이건 제대로 된 서비스구나" 하는 인상을 줘요.

그리고 하나 더. 요즘 링크는 **카톡에 붙이는 순간 미리보기 카드**(썸네일 이미지 + 제목 + 설명)가 뜨는 게 기본이에요. 이 카드가 안 뜨거나 깨져 있으면, 아무리 앱이 좋아도 클릭률이 확 떨어져요. 이 카드를 만드는 게 **OG(오픈그래프, SNS 미리보기용 정보)**라는 거예요. 이번 스텝에서 도메인 + 파비콘(브라우저 탭에 뜨는 작은 아이콘) + OG를 한 번에 챙깁니다.

## 이렇게 하세요

### (1) 도메인 사기 — "1년 임대"라고 생각하세요

도메인은 **사는 게 아니라 1년(또는 여러 해) 빌리는 것**이에요. 그래서 **첫해 가격과 갱신 가격을 반드시 같이** 봐야 해요. 첫해만 싸게 하고 다음 해부터 확 올리는 곳이 많거든요.

| 어디서 사나 | 언제 여기서 | 장점 | 주의 |
|---|---|---|---|
| **Cloudflare Registrar** | 글로벌 `.com`·`.app`·`.dev` | **원가 그대로 = 갱신 폭탄 없음**, DNS 화면 깔끔, WHOIS(소유자 정보) 프라이버시 무료 | **Cloudflare DNS를 써야** 살 수 있음. 한국 도메인(`.kr`)은 못 삼 |
| **가비아(Gabia)** | `.co.kr`·`.kr`, 또는 한국어 상담이 필요할 때 | **한국어 지원**, 국내 결제 편함 | 상대적으로 비쌈. (Cloudflare에선 한국 도메인 자체를 못 삼) |
| **Namecheap** | 글로벌 도메인, 첫해 저렴하게 | 첫해 값이 쌈 | **갱신가가 급등**하는 경우 많음 → 자동갱신·갱신가 꼭 확인 |

- **처음이고 `.com`이면:** Cloudflare Registrar가 가장 무난해요(갱신가가 안 뛰어서 나중에 놀랄 일이 없어요).
- **`.co.kr`을 원하거나 한국어로 물어가며 하고 싶으면:** 가비아.
- 어느 쪽이든 **자동갱신을 켜 두세요.** 깜빡하고 갱신을 놓치면 도메인이 남에게 넘어가요.

> 도메인 이름 정하기·구매는 **웹사이트에서 당신이 직접 결제**하는 부분이에요. 어디서 살지, 어떤 이름이 좋을지 헷갈리면 코치에게 물어보세요. 코치가 후보를 같이 골라줘요.

### (2) Vercel에 연결하기 — 코치가 값을 정확히 알려줘요

도메인을 샀으면 이제 Vercel 프로젝트에 연결해요. 절차 자체는 정해져 있어요:

1. Vercel 대시보드 → 내 프로젝트 → **Settings → Domains → Add Domain**.
2. 도메인을 입력해요. `myapp.com`(apex, 맨 앞에 아무것도 없는 주소)과 `www.myapp.com` **둘 다 추가**하는 걸 권장해요.
3. 연결 방식은 둘 중 하나예요(코치가 상황에 맞게 골라줘요):

| 방식 | 뭘 하나 | 누구에게 |
|---|---|---|
| **(A) 네임서버를 Vercel 것으로 교체** | 도메인 등록기관에서 네임서버를 `ns1.vercel-dns.com`, `ns2.vercel-dns.com`으로 바꿈 | **초보 추천.** 서브도메인 관리가 편함. 단, 기존에 쓰던 **메일(MX 레코드)이 있으면 Vercel 쪽에 다시 추가**해야 함 |
| **(B) 레코드 직접 추가** | 등록기관 DNS에 직접: apex `myapp.com` → **A 레코드 `76.76.21.21`** / `www` → **CNAME** | 이미 다른 DNS 설정이 많을 때 |

⚠️ **CNAME 값은 외우지 말고 대시보드에 표시된 값을 그대로 복사하세요.** 지금 일반적으로 보이는 값은 `cname.vercel-dns-0.com`이지만, **프로젝트마다 고유한 값**이 나올 수 있어요. 화면에 뜬 값이 정답이에요.

4. 값을 넣고 저장하면 Vercel이 **자동으로 검증**해요(Valid / Invalid 표시). 값이 맞으면 **SSL(https 자물쇠) 인증서도 자동 발급**(Let's Encrypt)돼요 — **당신이 손댈 건 없어요.**
5. **DNS 전파(변경이 전 세계에 퍼지는 것)는 몇 분에서 최대 48시간** 걸릴 수 있어요. 이건 **정상**이에요. 값이 맞으면 **그냥 기다리세요.** 조급해서 값을 계속 바꾸면 오히려 더 꼬여요.

### (3) 파비콘 — 파일만 놓으면 끝

파비콘(브라우저 탭에 뜨는 작은 아이콘)은 **파일을 정해진 위치에 놓기만** 하면 Next.js가 자동으로 인식해요. `app/` 폴더 바로 아래에:

- `favicon.ico` — 기본 파비콘
- `icon.png` — 일반 아이콘
- `apple-icon.png` — 아이폰 홈화면에 저장했을 때 쓰는 아이콘

만드는 법: 로고 PNG 하나를 **파비콘 생성 사이트**(예: favicon.io, realfavicongenerator.net)에 넣으면 `.ico` 등을 만들어줘요. 그 파일들을 코치가 제자리에 놓아줍니다.

### (4) OG — 카톡·SNS 미리보기 카드

`app/layout.tsx`의 `metadata`에 OG 정보를 넣어요. 짧게 예시를 보면:

```tsx
// app/layout.tsx
export const metadata = {
  metadataBase: new URL('https://myapp.com'), // ★ 이게 없으면 카톡 썸네일이 깨져요
  title: '내앱 — 한 줄 소개',
  description: '무엇을 하는 앱인지 한 문장.',
  openGraph: {
    title: '내앱 — 한 줄 소개',
    description: '무엇을 하는 앱인지 한 문장.',
    url: 'https://myapp.com',
    images: ['/og.png'], // 1200 x 630 권장
    locale: 'ko_KR',
  },
  twitter: { card: 'summary_large_image' },
}
```

- **`metadataBase`가 핵심이에요.** 이게 없으면 이미지 주소가 상대경로로 남아서 **카톡이 썸네일을 못 찾아 깨져요.** 꼭 내 도메인으로 넣어요.
- OG 이미지는 **가로 1200 × 세로 630**이 표준이에요. 이 비율이어야 카드가 안 잘려요.
- **더 쉬운 방법:** 이미지 파일 `app/opengraph-image.png` **하나만** 제자리에 놓으면, Next.js가 관련 태그를 **자동으로** 만들어줘요. 코드 없이 이미지만 바꾸고 싶으면 이 방법이 편해요.

### (5) ★ 한국 특화 — 카카오톡 OG 캐시 초기화

여기가 한국에서 제일 많이 당황하는 지점이에요. **카카오톡은 미리보기를 아주 강하게 캐싱(저장)해요.** 그래서 이미지를 바꿔도 카톡엔 **옛날 카드가 계속** 떠요. "분명 바꿨는데 안 바뀐다"의 90%가 이거예요.

새로고침하는 순서를 지키세요:

1. OG 이미지 교체 → 2. Vercel 재배포 → 3. **브라우저에서 새 이미지 URL(`myapp.com/og.png`)을 직접 열어** 새 이미지가 뜨는지 확인 → 4. **카카오 캐시 초기화** → 5. **새 대화방**에서 링크 재테스트.

카카오 캐시 초기화 방법:
- 카카오 계정으로 로그인 후 **`https://developers.kakao.com/tool/clear/og`** 에 접속.
- 내 URL을 입력해요. **`http`/`https`를 정확히** 맞춰서 넣어야 해요(주소가 조금만 달라도 다른 걸로 인식해요).
- **캐시 초기화** 버튼을 눌러요.
- 그다음 **이전에 테스트한 방이 아닌, 새 대화방**에서 링크를 다시 보내 확인해요(같은 방은 이미 카드를 기억하고 있어요).

## 🤖 AI(코치)에게 줄 프롬프트

도메인 연결:
```
내 도메인 [myapp.com]을 이 Vercel 프로젝트에 연결해줘.
- www 와 apex(myapp.com) 둘 다 추가하고 싶어.
- Vercel 대시보드가 요구하는 DNS 값(네임서버 또는 A/CNAME)을 정확히 알려줘.
  CNAME은 대시보드에 표시된 값 그대로 알려줘 (프로젝트별로 다를 수 있다고 했으니까).
- 나는 등록기관 화면에서 값을 넣기만 할게. 어디에 뭘 넣는지 한 단계씩 짚어줘.
- 전파는 기다려야 하는 거 알아. 값이 맞는지부터 같이 확인하자.
```

OG·파비콘:
```
app/layout.tsx에 OG(오픈그래프)와 트위터 카드 메타데이터를 넣어줘.
- metadataBase 를 https://[myapp.com] 로 꼭 포함해줘 (카톡 썸네일 깨짐 방지).
- og 이미지는 [문구/로고 설명]으로 1200x630 으로 만들어줘.
- 파비콘도 app/ 아래에 favicon.ico / icon.png / apple-icon.png 로 넣어줘.
  (로고 PNG는 [있다/없다] — 없으면 만드는 법 알려줘.)
- 다 되면 배포하고, 카톡 미리보기 확인 순서도 알려줘.
```

## ✅ 여기까지 하면 이렇게 보여요

- 브라우저 주소창에 **`myapp.com`**(내 도메인)을 치면 내 앱이 뜨고, 왼쪽에 **https 자물쇠**가 보여요.
- `www.myapp.com`으로 들어가도 같은 앱으로 연결돼요.
- 브라우저 탭에 **내 파비콘(작은 아이콘)**이 떠요.
- **새 카톡방**에 링크를 보내면 **미리보기 카드**(썸네일 + 제목 + 설명)가 예쁘게 떠요.
- **안 되면:** 미리보기가 옛날 걸로 뜨면 (5)번 카카오 캐시 초기화를 다시 하고, DNS가 아직이면 그냥 기다리세요. 에러 전문은 코치에게 그대로 붙이세요. → [[스텝08-막혔을때-에러-읽고-디버깅]]

> 코치는 내 도메인으로 접속이 되고(https 자물쇠 확인) 새 카톡방에서 미리보기가 제대로 뜨는 걸 확인한 뒤에만 `진행상태.md`의 이 줄을 `- [x]`로 바꾸고 `상태.json`을 갱신합니다.

## ⚠️ 자주 하는 실수

- **DNS 전파 중에 값을 계속 바꾸기.** 값이 맞으면 기다리는 게 정답이에요. 자꾸 바꾸면 더 늦어져요(최대 48시간 정상).
- **www·apex 리디렉션을 빠뜨리기.** `myapp.com`만 되고 `www.myapp.com`은 안 뜨면 반쪽이에요. 둘 다 추가하세요.
- **http·https 혼용(mixed content).** 코드 안에 `http://` 링크가 섞여 있으면 자물쇠가 깨지거나 이미지가 안 떠요. 전부 `https://`로.
- **`metadataBase`를 안 넣어서 카톡 썸네일이 깨지기.** 이게 없으면 카톡이 이미지를 못 찾아요. 내 도메인으로 꼭 넣으세요.
- **카톡 캐시를 안 지우고 "안 바뀐다"고 하기.** 카톡은 옛 카드를 강하게 기억해요. `developers.kakao.com/tool/clear/og`에서 초기화 후 **새 방**에서 테스트하세요.
