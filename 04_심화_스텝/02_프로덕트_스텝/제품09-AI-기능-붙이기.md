# 제품09 — AI 기능 붙이기 (LLM API, 키는 서버에)

## 🎯 이 스텝에서 하는 일 (한 줄)
앱에 **요약·태그·챗봇** 같은 지능을 붙이되, **AI에게 돈을 쓰는 비밀번호(API 키)가 새지 않게** 안전하게 연결합니다.

`⭐⭐ 보통 · 🕐 약 40분`

## 🔔 이 모듈이 필요한 신호
- 앱에 "이 글 요약해줘", "태그 자동 추천", "내 데이터로 챗봇" 같은 **지능**을 넣고 싶다.
- **AI 래퍼 제품**(내 데이터/UI에 AI 한 스푼 얹은 서비스)을 만들고 싶다.

## 왜 이렇게 하나

AI 기능이라고 하면 대단해 보이지만, 실제로 하는 일은 딱 이 흐름 하나예요.

```
입력 텍스트  →  API 호출  →  출력 텍스트  →  화면에 표시 / DB에 저장
```

여기서 **API**는 "**텍스트를 보내면 텍스트를 돌려주는 인터넷 주소(URL)**"예요. 우리가 노트 내용을 보내면, AI 회사 서버가 요약을 만들어서 돌려줍니다. 이미 스텝07에서 Supabase에 데이터를 "보내고 받는" 걸 해봤죠? AI도 똑같아요. 보낼 곳 주소만 다를 뿐이에요.

그러니까 **새로 배울 게 거의 없어요.** 딱 하나, **새롭고 위험한 것**이 있어요. 바로 **API 키**입니다.

### 황금률: 키는 서버에만 둔다

API 키는 "**돈을 쓰는 비밀번호**"예요. 이 키로 AI를 부를 때마다 내 계정에서 돈이 나갑니다. 그래서 이 키가 남의 손에 들어가면 **남이 내 돈을 씁니다.**

문제는 이거예요. **브라우저에서 도는 코드는 누구나 볼 수 있어요.** 크롬에서 F12(개발자도구)를 누르면 그 페이지의 코드가 다 보여요. 만약 API 키가 브라우저 코드에 들어 있으면, 아무나 F12로 키를 훔쳐서 내 돈으로 AI를 마음껏 씁니다. 이건 과장이 아니라 실제로 매우 흔한 사고예요.

그래서 규칙은 딱 하나예요. **LLM(AI 모델) 호출은 반드시 서버에서만 한다.**

Next.js에서 "서버"는 **Route Handler**(`app/api/.../route.ts` 파일)나 **Server Action**이에요. 쉽게 말해 "**브라우저가 아니라 내 서버 위에서만 도는 코드**"예요. 키는 여기에만 둡니다.

멘탈모델(머릿속 그림)로 그리면 이래요.

```
브라우저 (텍스트만 보냄, 키 없음)
   │
   ▼
내 서버 라우트  ←── 여기서 키를 붙임 (ANTHROPIC_API_KEY)
   │
   ▼
LLM (AI 회사 서버)
   │
   ▼
내 서버 → 브라우저 (결과 텍스트만 돌려줌)
```

**브라우저는 키를 절대 못 봅니다.** 브라우저는 그냥 "이 텍스트 요약해줘"라고 내 서버에 부탁하고, 키를 붙여서 AI를 부르는 건 내 서버가 대신 해요.

### ⚠️ 이름 하나가 대참사를 부른다: `NEXT_PUBLIC_` 금지

Next.js에는 무서운 규칙이 하나 있어요. 환경변수 이름 앞에 **`NEXT_PUBLIC_`**을 붙이면, 그 값이 **브라우저로 그대로 전송**됩니다. (원래는 공개해도 되는 값 — 예: 사이트 주소 — 을 위한 기능이에요.)

그래서 키 이름은 반드시 **`ANTHROPIC_API_KEY`** 처럼 지어야 하고, **절대 `NEXT_PUBLIC_ANTHROPIC_API_KEY`로 지으면 안 돼요.** 접두사 하나 잘못 붙이면 키가 통째로 브라우저에 노출되는 대참사예요.

| | 안전 ✅ | 대참사 ❌ |
|---|---|---|
| 키 이름 | `ANTHROPIC_API_KEY` | `NEXT_PUBLIC_ANTHROPIC_API_KEY` |
| 어디서 읽힘 | 서버에서만 | **브라우저로 전송됨(누구나 봄)** |

키는 `.env.local`이라는 파일에 넣고, 그 파일은 반드시 **`.gitignore`**(깃에 안 올리는 목록)에 넣어요. 실제 배포 서버(Vercel)에는 파일 대신 **Vercel 대시보드의 Environment Variables(환경변수)** 화면에 넣습니다. **이 처리는 전부 코치가 대신** 해줘요.

### 어떤 모델(AI 두뇌)을 쓸까 — 싼 것부터

AI 모델은 여러 급이 있어요. 똑똑할수록 비싸고 느려요. **첫 AI 기능은 반드시 제일 싼 것부터** 시작하세요. 요약·태그 정도는 싼 모델로도 충분해요.

가격은 **토큰**(글자 조각. 대략 한국어 1글자 ≈ 1~2토큰) 단위로 매겨지고, **100만(1M) 토큰당** 얼마로 계산해요. 아래는 2026년 기준 Claude 모델이에요. **모델 ID는 코드에 이 문자열 그대로** 넣어야 해요.

| 급 | 모델 ID (그대로 사용) | 입력 / 출력 (100만 토큰당) | 언제 |
|---|---|---|---|
| **기본값** ⭐ | `claude-haiku-4-5` | $1 / $5 | 요약·태그·간단 챗 — **여기서 시작** |
| 한 단계 위 | `claude-sonnet-4-6` | $3 / $15 | 품질이 부족할 때만 |
| 고난도 | `claude-opus-4-8` | (더 비쌈) | 복잡한 추론이 필요할 때 |
| 최상 | `claude-fable-5` | (가장 비쌈) | 정말 어려운 작업 |

(모델 ID `claude-haiku-4-5-20251001`처럼 날짜가 붙은 형태도 같은 모델이에요.)

**전략: 싼 것부터 시작 → 내 실제 데이터로 결과 품질을 직접 보고 → 정말 부족한 기능만 한 단어 바꿔 업그레이드.** 코드에서 모델 ID 한 글자만 `claude-haiku-4-5` → `claude-sonnet-4-6`으로 바꾸면 돼요. 첫 AI 기능에 `claude-opus-4-8`이나 `claude-fable-5`를 기본으로 쓰면 **5~25배 돈을 낭비**해요.

(동급 대안으로 Google의 Gemini Flash, OpenAI의 mini 모델도 있어요. 정확한 이름·가격은 각 회사 공식 페이지를 확인하세요.)

### 요금 폭탄을 막는 안전장치 (day1에 세팅)

AI는 부를 때마다 돈이 나가요. 특히 **출력이 입력보다 3~5배 비싸요**(위 표에서 오른쪽 숫자가 큰 이유). 누가 장난치거나 버그로 무한 반복되면 요금이 폭발할 수 있어요. 그래서 **첫날에** 아래를 세팅하세요.

- **① 콘솔에서 월 지출 한도(Spend limit) 설정 + 자동충전(auto-reload) 끄기.** Anthropic 콘솔(계정 관리 화면)에서 "이 달에 최대 얼마까지만 쓴다"를 걸어둬요. 크레딧을 **선불로** 사두고 자동충전을 끄면, 사둔 돈 이상은 절대 못 나가요 = **하드캡(절대 상한)**. 이게 요금 폭탄을 막는 가장 확실한 방법이에요.
- **② 싼 모델 쓰기** (위 표대로 `claude-haiku-4-5`).
- **③ 사용자별 레이트리밋(횟수 제한).** "한 사람이 시간당 10번까지만" 같은 제한을 걸어요. 로그인한 사용자의 Supabase user id를 열쇠 삼아 셉니다. 안 걸면 한 명이 크레딧을 다 태울 수 있어요.
- **④ `max_tokens` 제한.** AI 답변이 얼마나 길어질지 상한을 정해요(예: 요약은 300 토큰). 답이 무한정 길어지는 걸 막아요.
- **⑤ 반복 결과는 저장(캐시).** 같은 노트를 또 요약해달라고 하면, AI를 다시 부르지 말고 **Supabase에 저장해 둔 이전 결과를 재사용**해요. 돈도 아끼고 빨라요.

### 첫 AI 기능 아이디어 (쉬운 것부터)

1. **"이 노트 요약"** — 가장 쉬워요. 텍스트 넣고 요약 텍스트 받기.
2. **"태그 3~5개 제안"** — 구조화된 출력(JSON: 컴퓨터가 읽기 쉬운 형식)이라 조금 더 정교해요.
3. **"내 데이터 관련 챗"** — 챗봇.
4. **"글 다듬기"** — 문장 교정.
5. **"분류"** — 이건 긍정/부정 등으로 나누기.

**#1(요약)이나 #2(태그)로 시작하세요.** 나머지는 익숙해진 뒤에.

### 편하게 가고 싶다면: Vercel AI SDK

**Vercel AI SDK**(`ai` 패키지)는 초보에게 좋은 도구예요. `generateText`(한 번에 받기)·`streamText`(글자가 흘러나오게) 같은 함수를 주고, **AI 회사를 바꿀 때 한 줄만 고치면** 돼요. Next.js + Vercel 조합에 잘 맞아요. 단, **키를 서버에 두는 책임은 이걸 써도 똑같이 내 몫**이에요 — 도구가 바뀌어도 황금률은 안 바뀝니다.

## 이렇게 하세요

1. **AI 회사 계정과 키를 만드세요.**
   - Anthropic 콘솔(console.anthropic.com)에서 가입 → **API 키 발급**. 회원가입·버튼 누르는 부분은 당신이, 코치가 한 단계씩 짚어줘요.
   - **바로 여기서 지출 한도(Spend limit)를 걸고 자동충전을 끕니다.** 이걸 먼저 하는 게 중요해요.

2. **코치가 키를 서버에 안전하게 연결합니다.**
   - 코치가 `.env.local`에 `ANTHROPIC_API_KEY`를 넣고, `.env.local`이 `.gitignore`에 있는지 확인해요. `NEXT_PUBLIC_`은 절대 안 붙여요.
   - 당신이 할 일은 콘솔에서 받은 키를 코치에게 붙여주는 정도예요.

3. **첫 AI 기능(요약)을 하나만 붙이세요.**
   - 코치가 `app/api/summarize/route.ts`라는 **서버 파일**을 만들고, 거기서만 AI를 불러요. 브라우저의 버튼은 그 서버 주소로 텍스트만 보내요.
   - 한 번에 여러 기능 붙이지 말고 **요약 하나만** 먼저.

4. **직접 눌러보고, 키가 안 새는지 확인하세요.**
   - 요약 버튼이 실제로 동작하는지 눈으로 봐요.
   - 배포 사이트에서 F12(개발자도구) → 소스/네트워크를 봐서 `ANTHROPIC_API_KEY`가 **안 보이는지** 확인해요. (코치가 어디를 볼지 알려줘요.)

5. **잘 되면 코치가 저장점을 찍습니다.**

## 🤖 AI(코치)에게 줄 프롬프트

먼저 이걸로 붙이게 하세요. **안전 규칙을 프롬프트에 박아 넣는 게 핵심**이에요.

```
계획 먼저 말해줘. 어떻게 붙일 건지 설명하고, 그다음에 하자.

내 Next.js(App Router) + Supabase 앱에 "노트를 요약하는 AI 기능"을 붙여줘.
요약할 대상은 [예: 내 노트 한 개의 본문]. 나는 완전 초보야, 쉬운 말로 설명해줘.

반드시 지킬 안전 규칙:
① app/api/summarize/route.ts 라는 Route Handler(서버 파일)를 만들고,
   LLM 호출은 오직 이 서버 파일에서만 해.
② 키는 process.env.ANTHROPIC_API_KEY 에서 읽어. NEXT_PUBLIC_ 변수나
   클라이언트 컴포넌트('use client')에는 키를 절대 두지 마.
③ 브라우저는 /api/summarize 로 텍스트만 보내(키는 절대 안 보냄).
④ .env.local 에 키를 넣고, .env.local 이 .gitignore 에 있는지 확인해줘.
⑤ 공식 SDK(@anthropic-ai/sdk) 또는 Vercel AI SDK(ai 패키지)를 쓰고,
   모델은 claude-haiku-4-5 로 시작해. max_tokens 는 300 정도로 제한해.
⑥ 에러 처리를 넣고, per-user 레이트리밋(로그인 사용자 기준 시간당 10회)을 걸어줘.

끝나면 키가 쓰이는 모든 위치를 나한테 보여주고,
그 코드가 브라우저에서 안 돌고 서버에서만 도는지 확인해줘.
```

품질이 부족해서 모델을 올릴 때:

```
요약 품질이 좀 아쉬워. 요약 API의 모델 ID만 claude-haiku-4-5 에서
claude-sonnet-4-6 으로 바꿔줘. 다른 건 그대로. 바꾸고 나서 비용이
대략 얼마나 늘어나는지 한 줄로 알려줘.
```

## ✅ 여기까지 하면 이렇게 보여요

- **요약 버튼을 누르면 실제로 요약이 떠요.**
- 배포된 사이트에서 F12(개발자도구)의 소스나 네트워크를 봐도 **`ANTHROPIC_API_KEY`가 안 보여요.** (보이면 큰일 — 아래 실수 확인.)
- Anthropic 콘솔에 **지출 한도(Spend limit)가 걸려 있고 자동충전이 꺼져** 있어요.
- **안 되면:** 에러 전문을 그대로 코치에게 붙이세요. AI 연결 에러는 흔해요. → [[스텝08-막혔을때-에러-읽고-디버깅]]

> 코치는 "요약 동작 + 키 미노출 + 지출 한도 설정"을 눈으로 확인한 뒤에만 `진행상태.md`의 이 줄을 `- [x]`로 바꾸고 `상태.json`을 갱신합니다.

## ⚠️ 자주 하는 실수

- **`NEXT_PUBLIC_ANTHROPIC_API_KEY`로 이름 짓기.** 접두사 하나로 키가 브라우저에 노출되는 **대참사.** 반드시 `NEXT_PUBLIC_` 없이 `ANTHROPIC_API_KEY`.
- **`.env.local`을 깃에 커밋.** 키가 통째로 깃(코드 저장소)에 올라가요. `.gitignore`에 있는지 꼭 확인.
- **지출 한도 없음 + 자동충전 켜짐.** 요금 폭탄의 지름길이에요. day1에 한도 걸고 자동충전 끄기.
- **per-user 레이트리밋 없음.** 한 명이 크레딧을 다 태울 수 있어요. "시간당 N회"를 꼭 거세요.
- **기본 모델을 Opus/Fable로.** 요약·태그에 최고급 모델은 **5~25배 낭비.** `claude-haiku-4-5`부터 시작.
- **토큰 수를 tiktoken으로 추정.** tiktoken은 OpenAI용이라 **Claude엔 부정확**해요(15~20% 이상 어긋남). 비용을 정확히 재려면 Claude의 토큰 세는 방법을 써야 해요(코치에게 맡기세요).
- **LLM 호출을 클라이언트 컴포넌트('use client')에서 하기.** 그럼 키가 브라우저로 가요. 호출은 **무조건 서버 라우트에서만.**
