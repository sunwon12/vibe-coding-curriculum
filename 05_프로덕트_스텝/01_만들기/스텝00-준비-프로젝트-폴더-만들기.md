# 스텝00 — 준비: 프로젝트 폴더 만들기

## 🎯 이 스텝에서 하는 일
앞으로 만들 "내 앱"이 살 **빈 폴더 하나**를 만들고, 그 폴더를 Orca에서 연 뒤 Codex나 Claude Code를 실행해 코치가 준비를 도울 수 있게 합니다.

`⭐ 쉬움 · 🕐 약 15분`

## 왜 이렇게 하나

요리를 시작하기 전에 **깨끗한 도마 하나**를 꺼내 놓는 것과 같아요. 아직 재료(아이디어)도, 요리(코드)도 없지만, 앞으로 만들 것들이 **한곳에 모일 자리**를 먼저 비워 두는 거예요.

지금 당신이 읽고 있는 이 커리큘럼 폴더(설명서)와, 앞으로 만들 **내 앱 폴더**는 **완전히 다른 폴더**예요. 설명서 위에 요리를 하지 않듯이, 내 앱은 새 폴더에서 자랍니다. 그래서 첫걸음이 "빈 폴더 만들기"예요.

그리고 하나 미리 안심하세요. **터미널(컴퓨터에게 글자로 명령을 내리는 검은 창), 설치, 명령어 — 이런 건 당신이 외울 필요가 없어요.** 코치(AI)가 대신 실행하고, 무엇을 하는 중인지만 쉬운 말로 알려줄 거예요. 당신이 할 일은 "폴더 만들고, 열고, 코치에게 말 걸기" 딱 세 가지입니다.

## 이렇게 하세요

1. **내 컴퓨터에 앱용 새 폴더를 하나 만드세요.**
   - Mac이면 Finder(파인더), Windows면 파일 탐색기를 엽니다.
   - 바탕화면이나 문서 폴더 같은 찾기 쉬운 곳에서 마우스 오른쪽 클릭 → "새 폴더".
   - 폴더 이름은 영어나 한글로 알아보기 쉽게. 예: `내-첫-앱` 또는 `my-first-app`.
   - (이름에 띄어쓰기 대신 `-`(하이픈)을 쓰면 나중에 덜 꼬여요. 몰라도 코치가 챙겨줍니다.)

2. **Orca에서 그 폴더를 여세요.**
   - 아직 Git 저장소가 아니라서 **Add Repo**에 나타나지 않으면 코치에게 “이 폴더를 Git 저장소로 준비해서 Orca에 추가해줘”라고 말합니다.
   - Orca 파일 목록에 `내-첫-앱` 폴더가 보이면 맞습니다.

3. **AI 작업창을 엽니다.**
   - 저장소 옆 `+`를 누르고 공통 준비에서 고른 Codex 또는 Claude Code를 선택합니다.

4. **코치에게 준비를 부탁하세요.** (아래 프롬프트를 복붙)
   - 코치가 필요한 게 깔려 있는지 점검하고, 없으면 "지금 ~ 설치하는 중이에요"라고 알리며 대신 깔아줄 거예요.
   - 여기서 나오는 Node.js(자바스크립트를 컴퓨터에서 실행해 주는 프로그램) 같은 이름은 **몰라도 됩니다.** 코치가 알아서 확인·설치합니다.

## 🤖 AI(코치)에게 줄 프롬프트

```
나 완전 초보고, 이 빈 폴더에서 내 첫 웹앱을 만들 거야.
지금은 아직 코드를 만들지 말고, 만들 준비만 도와줘.

- 이 컴퓨터에 필요한 게 깔려 있는지 (예: Node.js 같은 실행기) 네가 대신 확인해줘.
- 없으면 네가 대신 설치해주고, 뭘 하는 중인지 쉬운 말로 한 줄씩 알려줘.
- 명령어는 내가 외우지 않아도 되게 네가 실행해줘.
- 다 되면 "준비 끝났어요"라고 말해줘.
```

## ✅ 여기까지 하면 이렇게 보여요

- 코치가 마지막에 **"준비 끝났어요"** 같은 말을 하면 성공이에요.
- 코치가 현재 작업 폴더의 끝이 **빈 프로젝트 폴더**(`내-첫-앱`)라고 확인합니다.
- **안 보이거나 막히면:** 코치에게 "지금 어떤 폴더에서 실행 중인지 알려줘"라고 물어보세요. 설치 중 빨간 글씨(에러)가 떠도 겁먹지 말고, 그 글씨를 **그대로 붙여넣으면** 됩니다. 에러는 정상이에요.

> 참고: **진짜 앱 코드**를 만드는 건 조금 뒤인 **스텝05**에서 해요. 지금은 "무엇을 만들지"부터 정하러 갑니다. 코치가 이 스텝이 끝난 걸 눈으로 확인하면 `진행상태.md`의 이 줄을 `- [x]`로 바꾸고 `상태.json`을 갱신해 줍니다.

## ⚠️ 자주 하는 실수

- **커리큘럼 폴더 안에 앱을 만들려는 것.** 이 설명서 폴더와 내 앱 폴더는 별개예요. 반드시 **새 빈 폴더**를 따로 만드세요.
- **폴더 이름에 띄어쓰기·특수문자.** `내 첫 앱!!` 같은 이름은 나중에 꼬일 수 있어요. `내-첫-앱`처럼 단순하게.
- **명령어를 내가 외워야 한다고 생각하는 것.** 아니에요. 터미널·설치는 코치 몫입니다.
- **아직 안 됐는데 "다 됐어요"라고 넘어가기.** 코치가 "준비 끝났어요"라고 확인해 줄 때까지 기다리세요.
