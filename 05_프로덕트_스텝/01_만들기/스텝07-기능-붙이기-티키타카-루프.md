# 스텝07 — 기능 붙이기: 티키타카 루프

## 🎯 이 스텝에서 하는 일
빈 화면에 **PRD의 필수 기능을 한 번에 하나씩** 붙여서, 실제로 동작하게 만듭니다.

`⭐⭐ 보통 · 🕐 약 40분+ (기능 수만큼 반복)`

## 왜 이렇게 하나

스텝05에서 뼈대(빈 방)를 세웠어요. 이제 그 방에 **가구를 하나씩** 들여놓습니다. 소파 놓고 → 앉아보고 → 괜찮으면 다음 거. 한꺼번에 트럭째 쏟아붓지 않아요.

바이브 코딩에서 초보가 앱을 무너뜨리는 가장 흔한 이유는 **"한 번에 여러 개를 시키는 것"**이에요. 다섯 기능을 한 프롬프트에 몰아넣으면, 뭔가 깨졌을 때 **어디서 깨졌는지 아무도 못 찾아요.** 그래서 원칙은 **한 번에 한 기능**입니다.

이 스텝에서 몸에 익힐 습관 3개예요:

| 습관 | 왜 |
|---|---|
| **기능마다 새 대화 세션** | 대화가 길어지면 AI가 앞 맥락에 헷갈려요. 기능 하나 끝나면 새 대화로 시작해 맥락을 깨끗하게 |
| **구체적으로 말하기** | "그냥 다 고쳐줘"가 아니라 **뭘 바꾸고 뭘 그대로 둘지** 콕 집어서. 이게 바이브 코딩 실력이에요 |
| **기능마다 저장점** | 저장점(git 커밋 = 지금 상태를 통째로 저장해 두는 것)을 찍어두면, 다음 작업이 망가져도 **여기로 되돌릴 수** 있어요 |

저장점은 게임의 **세이브 지점**과 같아요. 코치가 "저장점 찍을게요"라고 말하고 대신 찍어 줍니다. 명령어는 외울 필요 없어요.

## 이렇게 하세요

이건 **반복 루프**예요. 필수 기능을 **다 붙일 때까지** 아래 1~5를 계속 돌립니다.

1. **PRD의 필수 기능 목록에서 딱 하나를 고르세요.**
   - 예: 목록이 이미 보인다면 → 이번엔 "추가 버튼 누르면 목록에 새 항목이 실제로 추가되기".

2. **새 대화 세션을 열고, 편집 프롬프트를 줍니다.** (아래 프롬프트 복붙)
   - 편집 프롬프트의 3요소: **위치**(어디를) + **행동**(무엇을) + **가드레일**(뭘 건드리지 말지).

3. **코치가 만들면, 브라우저(localhost)에서 그 기능을 직접 눌러 확인하세요.**
   - 실제로 동작하나요? 버튼 누르니 목록에 추가되나요? 눈으로 확인.

4. **잘 되면 코치에게 저장점을 찍어달라고 하세요.** (프롬프트에 이미 포함돼 있어요)
   - 코치가 "저장점 찍었어요"라고 알려줍니다.

5. **다음 기능으로.** 새 대화를 열고 1번으로 돌아가세요.

> 필수 기능을 다 붙일 때까지 이 루프를 반복합니다. 서두르지 마세요 — 하나씩 확실히 쌓는 게 결국 제일 빨라요.

## 🤖 AI(코치)에게 줄 프롬프트

이미 있는 걸 고치는 **편집 요청**이라, **위치 + 행동 + 가드레일**로 씁니다. 대괄호 `[ ]`를 내 기능으로 바꾸세요.

```
계획 먼저 말해줘. 바로 코드 짜지 말고, 어떻게 할 건지부터 한 번 설명해줘.
그다음에 만들자.

[이 화면 / 여기: 예 "메인 화면의 '추가' 버튼"]에
[이 기능: 예 "누르면 위 입력칸의 제목이 아래 목록에 새 줄로 추가되는 기능"]을 붙여줘.

- [이 부분: 예 "지금 있는 목록 디자인이랑 상단 제목"]은 그대로 두고, 건드리지 마.
- 다 되면 브라우저에서 어떻게 눌러서 확인하는지 알려줘.
- 확인해서 잘 되면 저장점(커밋) 찍어줘.
```

> 팁: "계획 먼저 말해줘"를 넣으면, 코치가 곧장 코드를 쏟기 전에 **어떻게 할지** 먼저 설명해요. 방향이 이상하면 여기서 잡을 수 있어요.

## ✅ 여기까지 하면 이렇게 보여요

- 방금 고른 **기능 하나가 브라우저에서 실제로 동작**해요 (버튼 누르니 목록에 추가되는 등).
- 코치가 **"저장점 찍었어요"**라고 확인해 줬어요.
- **안 되면:** 뭐가 안 되는지("추가 버튼 눌러도 아무 일도 안 일어나")를 구체적으로 코치에게 말하고, 에러가 있으면 전문을 붙이세요. → [[스텝09-막혔을때-에러-읽고-디버깅]]

> 코치는 기능 하나가 동작하는 걸 확인할 때마다 저장점을 찍고, 필수 기능을 다 붙이면 `진행상태.md`의 이 줄을 `- [x]`로 바꾸고 `상태.json`을 갱신합니다.

## ⚠️ 자주 하는 실수

- **한 프롬프트에 기능 5개 몰아넣기.** 깨지면 못 찾아요. **한 번에 하나.**
- **저장점 없이 계속 쌓기.** 세이브 안 하고 게임하다 죽는 것과 같아요. 기능마다 저장점.
- **"그냥 다 알아서 고쳐줘"라고 하기.** 뭘 바꾸고 뭘 그대로 둘지 **구체적으로.** 안 그러면 멀쩡한 부분까지 바뀌어요.
- **한 대화에서 기능 여러 개를 이어서 시키기.** 기능 하나 끝나면 **새 대화**로. 맥락을 깨끗하게.
