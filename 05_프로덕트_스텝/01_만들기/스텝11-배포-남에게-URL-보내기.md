# 스텝11 — 배포: 남에게 URL 보내기

## 🎯 이 스텝에서 하는 일
내 컴퓨터에서만 열리던 앱을 **인터넷에 올려서**, 친구에게 링크로 보낼 수 있게 만듭니다. **결승선이에요 🚀**

`⭐⭐ 보통 · 🕐 약 30분`

## 왜 이렇게 하나

지금까지 앱은 **당신 컴퓨터 안(localhost, "이 컴퓨터에서만 열리는 주소")에서만** 열렸어요. 이걸 "배포(deploy)"라는 과정으로 인터넷에 올리면, **누구나 링크 하나로** 열 수 있게 됩니다.

배포는 두 단계예요:

| 도구 | 쉽게 말하면 | 하는 일 |
|---|---|---|
| **GitHub** | 코드를 올려두는 **공유 창고** | 내 앱 코드를 인터넷 창고에 올림 |
| **Vercel** | 그 창고를 받아 **웹사이트로 켜주는 무료 서비스** | 창고에 있는 코드로 진짜 주소(`...vercel.app`)를 만들어 줌 |

둘 다 **무료**로 됩니다. 그리고 배포는 마지막에 딱 한 번 하는 게 아니라 **일찍, 자주** 하는 게 좋아요 — 실제 인터넷에서 돌려봐야 진짜 문제가 보이거든요.

**여기서 딱 하나만 꼭 기억하세요: 환경변수.** 당신 컴퓨터에는 Supabase 열쇠(키) 같은 비밀값이 `.env` 파일에 들어 있어요. 그런데 이 `.env` 파일은 (보안 때문에) 창고에 **안 올라가요.** 그래서 **Vercel 쪽에도 똑같은 비밀값을 따로 등록**해 줘야 합니다. 이걸 빼먹으면 "내 컴퓨터에선 되는데 인터넷 배포판만 깨지는" — **가장 흔한 배포 실패**가 일어나요.

## 이렇게 하세요

1. **코치가 GitHub·Vercel 무료 계정을 손잡고 안내해줘요.**
   - 아직 계정이 없으면 코치가 어디서 어떻게 가입하는지 한 단계씩 알려줍니다. (둘 다 무료 플랜으로 충분해요.)

2. **코치가 코드를 GitHub 창고에 올리고, Vercel에 연결해줘요.**
   - 창고 만들기·올리기·연결은 전부 코치가 대신 합니다. 명령어는 외울 필요 없어요.
   - "지금 GitHub에 올리는 중이에요", "Vercel에 연결하는 중이에요"처럼 무슨 일 하는지 알려줄 거예요.

3. **⚠️ 중요 — 환경변수를 Vercel 대시보드에도 똑같이 등록하세요.**
   - Supabase 키 같은 비밀값을, Vercel 설정 화면(대시보드)에 `.env`에 있던 것과 **똑같은 이름·값으로** 넣습니다.
   - 코치가 "어떤 값을 어디에 붙여넣으면 되는지" 짚어줄 거예요. **이걸 안 하면 배포판만 깨집니다.**

4. **발급된 주소를 폰으로 열어, 실사용자처럼 테스트하세요.**
   - `https://무언가.vercel.app` 같은 주소가 나오면, 그걸 **당신 폰**으로 열어봅니다.
   - 저장·목록·로그인이 폰에서도 되는지 실제로 눌러보세요. 진짜 사용자처럼요.

5. **배포 주소를 `진행상태.md`의 "내 프로젝트 메모"에 기록하세요.**
   - "배포 주소:" 칸에 나온 주소를 적어둡니다. (코치가 대신 적어줄 수도 있어요.)

## 🤖 AI(코치)에게 줄 프롬프트

```
내 앱을 인터넷에 배포하고 싶어. 나 완전 초보니까 손잡고 이끌어줘.

- GitHub랑 Vercel 계정이 필요하면, 어디서 어떻게 무료로 가입하는지 한 단계씩 알려줘.
- 내 코드를 GitHub에 올리고 Vercel로 배포하는 건 네가 대신 해줘.
- 중요: 내 .env에 있는 환경변수(Supabase 키 등)를 Vercel 대시보드에도 똑같이
  넣어야 하는 거 잊지 마. 어떤 값을 어디에 붙여넣는지 짚어줘.
- 다 되면 접속 주소(.vercel.app)를 알려줘. 폰에서 열어서 확인할 거야.
- 배포판이 깨지면 환경변수 누락부터 같이 확인해줘.
```

## ✅ 여기까지 하면 이렇게 보여요

- `https://...vercel.app` 같은 **진짜 인터넷 주소**가 나옵니다.
- 그 주소를 **폰으로 열면** 앱이 뜨고, 저장·목록·로그인이 동작해요.
- **친구에게 링크로 보낼 수 있어요.** 이게 결승선입니다 🚀
- **배포판이 깨지면 → 환경변수 누락부터 의심하세요.** "내 컴퓨터에선 되는데 배포 주소에서만 안 된다"면 거의 항상 이거예요. 코치에게 "Vercel에 환경변수 다 들어갔는지 확인해줘"라고 하세요. 그래도 안 풀리면 [[스텝09-막혔을때-에러-읽고-디버깅]] 방식으로 에러 전문을 그대로 붙여 함께 고칩니다.

> 코치는 배포 주소가 폰에서 실제로 열리는 걸 확인하면 `진행상태.md`의 이 줄을 `- [x]`로, "배포 주소" 메모와 `상태.json`을 갱신해 줍니다.

## ⚠️ 자주 하는 실수

- **환경변수를 Vercel에 안 넣는 것.** 배포판만 에러 나는 1위 원인이에요. `.env`는 창고에 안 올라가니 Vercel에 따로 등록해야 합니다.
- **진짜 개인정보로 테스트하는 것.** 실제 이름·전화번호·비밀번호 말고, `테스트`·`홍길동` 같은 가짜 데이터로 확인하세요.
- **배포하고 확인을 안 하는 것.** 주소만 받고 안 열어보면 깨진 걸 모릅니다. 꼭 폰으로 직접 눌러보세요.
- **한 번 배포로 끝내려는 것.** 배포는 일찍·자주. 고칠 때마다 다시 올리면 됩니다.
