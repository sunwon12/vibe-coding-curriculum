# 바이브 코딩, 처음부터 배포까지 — 비개발자를 위한 커리큘럼

> 코딩을 한 줄도 안 해봤어도 괜찮아요. 이 폴더를 AI에게 열어주면, AI가 **선생님(바이브 코치)**이 되어
> 단계별로 당신을 이끌어 줍니다. 끝까지 따라오면 **당신만의 웹앱 하나를 인터넷에 올려서 친구에게 링크로
> 보낼 수 있게** 됩니다.

## 이게 뭔가요?

이건 "읽는 강의"가 아니라 **AI와 함께 실제로 만드는 워크북**이에요.
당신은 AI(바이브 코치)와 채팅으로 **티키타카(주고받는 대화)**를 하면서 하나씩 만들어 나갑니다.
바이브 코딩이 뭔지 글로 배우는 게 아니라, **직접 해보면서 몸으로 알게** 되는 게 목표예요.

## 3분 안에 시작하기

1. **도구를 설치하세요.** 이 커리큘럼은 **Cursor**(AI가 들어있는 코딩 프로그램) 또는 **Antigravity**(구글, 완전 무료)로 진행해요.
   둘 다 이 폴더를 읽고 AI 코치가 이끌어 줍니다 — **돈을 안 쓰고 싶으면 Antigravity, 편집이 더 부드러운 건 Cursor.**
   설치가 막막하면 걱정 마세요 — `00_시작하기/02_도구-고르기와-설치-Cursor.md`가 둘 다 손잡고 알려줍니다.
   (터미널이 부담되면 Lovable 같은 더 쉬운 대안도 그 문서에 있어요.)
2. **이 폴더를 내 컴퓨터로 가져오세요.** 지금 이 글을 **깃허브 웹페이지에서** 보고 있다면, 파일은 아직 **인터넷에만** 있어요.
   가장 쉬운 길은 초록색 **`Code` 버튼 → `Download ZIP` → 압축 풀기.**
   ("원격이랑 로컬이 뭔지, ZIP과 clone이 뭐가 다른지" 궁금하면 → `00_시작하기/04_원격과-로컬-깃허브와-내-컴퓨터-연결하기.md`.
   여기서 막히는 분이 제일 많아요. 딱 20분이고, 명령어는 안 외워도 돼요.)
3. **그 폴더를 Cursor로 여세요.** (`파일 → 폴더 열기`에서 압축 푼 폴더 선택)
4. **AI 채팅창(Cursor에서 `Cmd/Ctrl + I`)을 열고 이렇게 말하세요:**

   ```
   나 이 레포로 바이브 코딩 처음 배워. 완전 초보야.
   AGENTS.md 규칙대로 바이브 코치가 되어서, 지금 몇 스텝인지 확인하고 처음부터 이끌어줘.
   ```

   그러면 AI가 `상태.json`을 읽고 "지금 스텝 00 차례예요, 시작할까요?"라고 말을 걸 거예요.
   이제부터는 AI가 안내하는 대로 따라가면 됩니다.

## 어떻게 흘러가나요?

```
00_시작하기   →   바이브 코딩이 뭔지 + 도구 설치 + AI랑 대화하는 법 (읽기만)
      │
01_스텝        →   [발산] 무엇을 만들까 → [좁히기] 한 문장 → [PRD] 기획을 대화로
                   → [화면] 한 장으로 → [첫 화면 뽑기 🎉] → [기능 붙이기] → [데이터 저장]
                   → [디버깅] → [다듬기] → [배포 🚀] → [회고]
      │
결과          →   인터넷에 올라간, 링크로 공유되는 나만의 웹앱 하나
```

## 폴더 안내

| 폴더/파일 | 무엇인가요 |
|---|---|
| `00_시작하기/` | 시작 전에 읽는 6개 글 (겁먹지 않게 준비시켜 줘요 — 깃허브↔내 컴퓨터 연결, 만드는 순서 포함) |
| `01_스텝/` | 실제로 만드는 12개 스텝. AI가 여기 순서대로 이끌어요 |
| `02_템플릿/` | 당신이 채워 나가는 서류 (아이디어·PRD·화면정의·작업로그) |
| `03_레퍼런스/` | 복붙용 프롬프트 모음 · 자주 막히는 것 FAQ · 용어집 · "AI가 못하는 것" 진단표 |
| `04_심화_스텝/` | (선택) 첫 배포 뒤 레벨업 — 로그인·보안·AI기능·결제·도메인·성장·모바일. 필요한 것부터 골라요 |
| `진행상태.md` | 지금 어디쯤 왔는지 보여주는 지도 (AI가 관리) |
| `상태.json` | AI가 "지금 몇 스텝"인지 읽는 파일 (건드리지 않아도 돼요) |
| `AGENTS.md` | AI에게 "바이브 코치가 되라"고 지시하는 규칙 파일 |

## 마음가짐 딱 3개

- **완벽하지 않아도 돼요.** 일단 돌아가게 만들고, 그다음에 다듬어요.
- **에러(빨간 글씨)는 정상이에요.** 개발자도 하루 종일 에러를 봐요. 그대로 AI에게 붙여넣으면 같이 고쳐요.
- **AI에게 "알아서 다 해줘"보다, 내가 뭘 원하는지 구체적으로 말하는 게 실력이에요.**

자, `00_시작하기/00_이-레포를-쓰는-법.md`부터 시작해요. 또는 위 "3분 안에 시작하기"대로 AI에게 바로 말을 걸어도 돼요.
