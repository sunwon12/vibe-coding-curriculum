# AI로 내 일을 줄이거나 제품을 만들기 — 비개발자를 위한 커리큘럼

> 코딩을 한 줄도 안 해봤어도 괜찮아요. 이 폴더를 AI에게 열어주면 AI가 **선생님(바이브 코치)**이 됩니다.
> 먼저 목적을 고르세요. **AI에게 내 지식과 도구를 연결해 반복 업무를 줄이거나**, **내 웹앱을 만들어 인터넷에 배포**할 수 있습니다.

## 이게 뭔가요?

이건 "읽는 강의"가 아니라 **AI와 함께 실제 일을 끝내는 워크북**이에요.
코드를 읽는 공부부터 시작하지 않습니다. 코치와 대화하며 내 자동화 하나를 만들거나, 웹앱 하나를 직접 완성합니다.

## 3분 안에 시작하기

1. **이 폴더를 내 컴퓨터로 가져오세요.** 지금 이 글을 **깃허브 웹페이지에서** 보고 있다면, 파일은 아직 **인터넷에만** 있어요.
   가장 쉬운 길은 초록색 **`Code` 버튼 → `Download ZIP` → 압축 풀기.**
2. **Orca와 AI 하나를 설치하세요.** `00_시작하기/02_AI-도구-고르고-CLI-설치하기.md`를 보고 Orca를 설치한 뒤 **Codex CLI 또는 Claude Code 중 이미 쓰는 계정에 맞는 것 하나만** 고릅니다. 그때그때의 모델 순위보다 내 로컬 파일을 직접 읽고 고칠 수 있는지가 중요합니다.
3. **GitHub 체크포인트를 준비하세요.** `00_시작하기/03_GitHub로-체크포인트와-동기화-만들기.md`를 따라 계정·저장소를 연결하면 잘 되던 순간으로 돌아가고 다른 컴퓨터에서도 이어 할 수 있습니다.
4. **Orca의 `Add Repo`에서 이 폴더를 열고** 저장소 옆 `+`에서 Codex 또는 Claude Code를 실행하세요.
5. **열린 AI 작업창에 이렇게 말하세요:**

   ```
   나 이 레포로 바이브 코딩 처음 배워. 완전 초보야.
   AGENTS.md 규칙대로 바이브 코치가 되어서, 지금 몇 스텝인지 확인하고 처음부터 이끌어줘.
   ```

   그러면 AI가 `상태.json`과 `진행상태.md`를 읽고 **Orca·AI CLI·GitHub·작업 의뢰법 공통 준비부터** 확인합니다. 준비가 끝나면 AI 스텝과 프로덕트 스텝 중 무엇을 할지 묻습니다. 코딩 없이 내 일을 줄이고 싶으면 AI 스텝, 웹앱을 만들고 싶으면 프로덕트 스텝을 고르세요.

## 어떻게 흘러가나요?

```
00_시작하기
      │
      ├─ 04_AI_스텝 → 자동화 후보 → 지식베이스 → 암묵지 → 주입·호출 설계 → 손발 → Skill
      │                결과: 내 일을 내 기준으로 반복 수행하는 AI
      │
      └─ 05_프로덕트_스텝
           ├─ 01_만들기 → 아이디어 → PRD → 화면 → 기능 → 데이터 → 배포
           │               결과: 링크로 공유되는 나만의 웹앱
           └─ 02_키우기 → 로그인·보안·결제·성장·운영
```
